# 지역축제 서비스 기획 정의서

본 문서는 지도 중심 풀스크린(Full-Screen) 인터랙티브 플랫폼으로 전면 개편된 '지역축제' 서비스의 화면 구조, 기능 사양, 정책 및 데이터 연동 규격을 기술함.

---

## 1. 서비스 개요

### 1.1. 서비스 목적
- 전국 각지의 축제 정보를 브라우저 전체화면 지도 기반에서 직관적으로 탐색할 수 있는 서비스 제공함.
- 복잡한 스크롤 및 불필요한 탐색 동선을 제거하고 위치, 지도 인터랙션, 추천 단축키 중심의 빠른 탐색 환경을 구축함.

### 1.2. 기본 운영 원칙
- **화면 구조 단순화**: 페이지 진입 시 미니멀 헤더와 지도만 노출하며, 하단 스크롤 영역(큐레이션 섹션 등)을 전면 제거함.
- **뷰포트 풀사이즈 지도**: 브라우저 창 전체 높이(`100vh - 헤더높이`)를 지도로 채워 시각적 몰입감을 극대화함.
- **일일 1회 정기 갱신**: 한국관광공사 TourAPI 데이터를 매일 1회 정기 동기화하여 자체 데이터베이스로 관리함.

---

## 2. 화면별 상세 구성 및 기능 사양

### 2.1. 헤더 영역 (최상단)
- **배치 정책**: 유틸리티 링크(신문구독, 로그인, 관리자, 기획문서 등) 및 GNB 서브 메뉴 전면 배제함.
- **구성 요소**:
  - 좌측: 한경 트래블 공식 로고 + 세로 구분선 + `지역축제` 서비스 타이틀 배치함.
  - 우측: 완전 빈 공간으로 유지하여 미니멀한 브랜드 헤더로 구성함.
- **높이**: 지도 시야를 최대한 확보할 수 있도록 상단 고정(`sticky`) 컴팩트 높이(56px) 적용함.

### 2.2. 전면 풀사이즈 지도 및 내 위치 컨트롤
- **지도 상단 말풍선 제거**: 불필요한 시야 방해 요소인 '전국 실시간 축제 지도' 안내 말풍선은 전면 삭제함.
- **내 위치 이동 버튼**:
  - 우측 하단(`bottom-6 right-6`)에 고정 배치하여 엄지손가락 및 마우스 조작 편의성을 극대화함.
  - 클릭 시 사용자 브라우저 GPS 좌표를 획득하여 해당 위치로 지도 중심 이동 및 마커 포커싱 처리함.
- **지도 인터랙션**:
  - 마커 클러스터링 및 축제 위치 개별 마커 표기함.
  - 마커 클릭 시 요약 팝업(썸네일, 상태 뱃지, 축제명, 기간, 주소, `상세보기` 버튼) 노출함.
  - 지도 이동/확대/축소 시 현재 화면 좌표 범위(`Bounds`) 내 축제 목록을 패널에 실시간 연동함.

### 2.3. 좌측 검색 및 추천 필터 모듈 (PC 환경)
- **배치**: 지도 좌측 상단 플로팅 오버레이 패널 (`top-3 left-3 bottom-3`, 패널 우측 토글 탭 버튼 지원함).
- **모듈 내부 구성 (상단 -> 하단)**:
  1. **모듈 헤더 유틸리티**:
     - 결과 건수 표기: 기존 '화면 내 축제' 대신 `축제 검색결과` 문구로 직관성 부여함.
     - **검색/필터 초기화 버튼**: 우측 상단에 배치 (`새로고침` 아이콘 + `초기화` 텍스트). 클릭 시 검색어 빈값, 추천 배너 토글 해제, 일정 탭 '전체 일정', 상태 '진행 중' 기본값으로 원클릭 리셋됨.
  2. **강화된 검색어 입력창**:
     - 시인성을 강화한 진한 테두리(`border-2 border-slate-300`) 및 뚜렷한 포커스 대비 색상 적용함.
     - 안내 문구(Placeholder): `"축제명 또는 주소를 입력하세요."`
     - 검색어 즉시 삭제(`X`) 버튼 지원함.
  3. **추천 배너 3종 (세로 나열 가로형 배너 디자인)**:
     - '추천목록' 텍스트 레이블은 전면 삭제하여 화면 군더더기를 제거함.
     - 기존 4종 중 4번(가족·체험)을 삭제하고 핵심 3종으로 압축함:
       - `[HOT 10 축제]`: 지금 가장 주목받는 인기 축제 (오렌지/앰버 그라데이션 배너)
       - `[뮤직 & 페스티벌]`: 음악·공연·버스킹·락 축제 (블루/인디고 그라데이션 배너)
       - `[야간 & 빛 축제]`: 낭만 가득 불꽃·달빛·드론쇼 (퍼플/네이비 그라데이션 배너)
     - 배너 클릭 시 해당 테마가 원터치 필터링되며, 활성화 상태에서 재클릭 시 필터가 해제되는 토글 방식으로 작동함.
  4. **일정 탭 칩**:
     - 구성: `[전체 일정]`, `[이번 주]`, `[이번 달]`
  5. **진행 상태 필터**:
     - 체크박스: `진행 중`, `진행 예정`, `종료`
  6. **연동 축제 카드 목록**:
     - 세로 스크롤 카드 리스트 (카드 클릭 시 지도 위치 포커싱 및 팝업 활성화).

### 2.4. 모바일 화면 인터랙션 (모바일 환경)
- **기본 화면**: 모바일에서도 지도가 전체 화면을 차지하며 상단에 검색 바 및 우측 내 위치 버튼 배치함.
- **축제 검색결과 전체 덮기 팝업 (Full Overlay)**:
  - 상단 검색창 터치 시 모바일 화면 전체를 덮는 축제 검색결과 및 추천 배너 목록 활성화됨.
  - 상단에 `'지도로 보기'` 닫기 버튼을 제공하여 언제든 지도 화면으로 원터치 복귀함.

## 3. 추천 테마 데이터 필터링 규칙

1. **[HOT 10 축제]**:
   - 진행 중(최근 개막 축제) 및 오픈 임박 진행 예정 축제 결합 노출함.
2. **[뮤직 & 페스티벌]**:
   - `title` 또는 `overview` 정규식 `뮤직|락|재즈|콘서트|페스티벌|음악|버스킹|비어|맥주` 매칭.
3. **[야간 & 빛 축제]**:
   - `title` 또는 `overview` 정규식 `야간|빛|불꽃|달빛|밤|나이트|드론` 매칭.
