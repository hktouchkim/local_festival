# 지역축제 서비스 기획 정의서

본 문서는 전국 축제 정보를 제공하는 '지역축제' 서비스의 화면 구조, 기능 사양, 정책, 큐레이션 데이터 추출 기준 및 데이터 연동 규격을 정의함.

---

## 1. 서비스 개요

### 1.1. 서비스 목적
- 전국 각지의 축제 정보를 직관적으로 제공하여 주말 나들이 및 여행 일정 탐색 편의성을 제공함.
- 한국관광공사 TourAPI 공공 데이터를 연동·가공하여 독자적인 축제 정보 플랫폼을 구축함.

### 1.2. 디바이스별 기본 운영 원칙
- **일일 1회 정기 갱신**: 한국관광공사 TourAPI 데이터를 매일 1회 정기 동기화하여 자체 데이터베이스로 관리함 (실시간 외부 API 호출 배제).
- **디바이스별 탐색 구조 차별화**:
  - **PC 환경**: 상단 전면 인터랙티브 지도(마커 및 오버레이 연동) + 하단 4대 테마 큐레이션 구조를 유지함.
  - **모바일 환경**: 작은 화면에서의 터치 간섭 및 탐색 피로도를 방지하기 위해 **지도를 완전히 미제공**함. 첫 진입 시 4대 테마 큐레이션을 최우선 노출하고, 그 하단에 [검색 필터 + 결과 카드 리스트] 일체형 모듈을 배치함.
- **자체 화면 완결형 제공**: 상세 화면 내 모든 정보를 완결형으로 제공함.

## 2. 사용자 이용 흐름

```
[상단 메뉴]
   │
   ▼ ('지역축제' 클릭)
[메인 화면]
   │
   ├─► [PC 환경]
   │       ├─► 1. 상단 전면 지도 영역 (플로팅 검색 바, 마커 팝업, 축제 목록 패널)
   │       └─► 2. 하단 4대 테마 큐레이션 캐러셀 영역
   │
   ├─► [모바일 환경] (지도 미제공)
   │       ├─► 1. 4대 테마 큐레이션 캐러셀 영역 (최상단 우선 배치)
   │       │       - 지금 가장 핫한 축제 TOP 10
   │       │       - 흥 폭발! 뮤직 & 페스티벌
   │       │       - 낭만 가득 야간 & 빛 축제
   │       │       - 온 가족 & 아이와 함께 가기 좋은 축제
   │       │
   │       └─► 2. 검색 필터 및 결과 리스트 일체형 모듈 (큐레이션 하단 배치)
   │               ├─► 검색창 (축제명 및 지역명 검색)
   │               ├─► 일정 탭 (전체 / 이번 주말 / 이번 달)
   │               ├─► 지역 태그 선택 (전국 / 서울 / 경기·인천 등)
   │               ├─► 상태 필터 선택 (진행중 / 예정 / 종료)
   │               └─► 필터링된 축제 세로 1열 카드 목록 (총 건수 표기 및 상세 이동)
   │
   └─► [축제 상세 화면] (카드 선택 시 이동)
```

## 3. 메인 화면 구성 및 상세 기능 정의

### 3.1. 상단 지도 탐색 영역 (PC 환경 전용)
- **지도 화면 배치**: 화면 상단에 지도를 배치하여 전국 단위 축제 위치를 한눈에 파악할 수 있도록 구성함 (모바일 환경에서는 미제공).
- **검색 및 필터 기능**:
  - 축제명 검색창: 키워드 입력 및 실시간 검색어 초기화 기능 제공함.
  - 일정 필터: `전체 일정`, `이번 주말`, `이번 달` 단위의 빠른 선택 탭 제공함.
  - 지역 필터: `전국`, `서울`, `경기/인천`, `강원`, `충청`, `전라`, `경상`, `제주` 단위 선택 버튼 제공함.
  - 상태 필터: `진행중`, `예정`, `종료` 상태별 체크박스 필터 제공함.
- **내 위치 탐색**: 위치 정보 제공 동의 시 사용자의 현재 위치로 지도 중심을 이동함.
- **지도 마커 및 팝업**:
  - 축제 위치에 마커를 표기함.
  - 마커 선택 시 썸네일, 상태 뱃지, 축제명, 기간, 주소, `상세보기` 버튼이 포함된 팝업을 노출함.
  - `상세보기` 선택 시 해당 축제 상세 화면으로 이동함.
- **축제 목록 패널**:
  - 지도 한쪽에 검색 결과에 해당하는 축제 목록을 제공함.
  - 목록 접기/펼치기 기능을 제공하여 지도 시야를 확보할 수 있도록 지원함.
  - 목록 내 축제 선택 시 지도의 해당 마커 위치로 이동하고 팝업을 노출함.

### 3.2. 모바일 검색 및 목록 일체형 모듈 (모바일 환경 전용)
- **배치 위치**: 4대 테마 큐레이션 섹션 하단에 배치함.
- **상단 필터부**:
  - 축제명/지역명 검색창 (초기화 버튼 지원).
  - 지역 선택 칩 버튼 목록 (`전국` ~ `제주`).
  - 일정 선택 칩 버튼 목록 (`전체 일정`, `이번 주말`, `이번 달`).
  - 진행 상태 체크박스 (`진행 중`, `진행 예정`, `종료`).
- **하단 결과 목록부**:
  - 필터링 결과 총 건수 표기.
  - 세로 1열 축제 카드 리스트 (썸네일, 상태 뱃지, 축제명, 기간, 주소, 상세보기 버튼).
  - 검색 결과 0건 시 빈 화면 안내 컴포넌트 표출.

## 4. 메인 4대 테마 큐레이션 데이터 추출 및 정렬 상세 정책

본 항은 메인 화면 4대 테마 큐레이션 캐러셀에 노출되는 축제 데이터의 추출 조건, 키워드 매칭 규칙, 정렬 우선순위 및 예외 처리 정책을 정의함.

### 4.1. 공통 데이터 추출 전제 조건
- **상태값 필터**: 관리자가 공개 처리한 축제(`status = 'PUBLISHED'`)만 노출함.
- **대표 썸네일 필수 요건**: 큐레이션 카드의 시각적 품질 유지를 위해 대표 이미지 URL(`firstimage`)이 등록되어 있고 빈 값이 아닌 축제를 최우선 추출함.
- **과거 종료 축제 배제**: 서비스 기준일(`SERVICE_TODAY`) 기준 이미 종료된 축제는 큐레이션 노출 대상에서 자동 제외함.

### 4.2. 테마 1: [지금 가장 핫한 축제 TOP 10]
- **기획 목적**: 현재 진행 중인 대표 축제와 곧 시작되는 기대 축제를 균형 있게 배치하여 사용자에게 즉시 방문 가능한 정보와 사전 예약·계획 정보를 동시 제공함.
- **노출 구성**: 총 10~12건 (진행 중 최대 6건 + 진행 예정 최대 6건 균형 결합).
- **세부 추출 로직**:
  1. **진행 중 축제 (그룹 1, 우선순위 1)**:
     - 조건: `start_date <= 기준일 AND end_date >= 기준일`
     - 최신성 필터: 시작일이 기준일 기준 20일 이전(`start_date >= '기준일 - 20일'`)인 최근 개막 축제 대상.
     - 정렬: 시작일 최신순(`start_date DESC`)으로 최대 6건 추출.
  2. **진행 예정 축제 (그룹 2, 우선순위 2)**:
     - 조건: `start_date > 기준일`
     - 정렬: 시작일 임박순(`start_date ASC`, D-Day 오름차순)으로 최대 6건 추출.
  3. **최종 결합 정렬**: 진행 중 그룹 6건 선순위 배치 후 진행 예정 그룹을 순차 배치함.

### 4.3. 테마 2: [흥 폭발! 뮤직 & 페스티벌]
- **기획 목적**: 락, 재즈, 음악, 맥주, 버스킹 등 음악과 공연 중심의 역동적인 페스티벌 선별 제공.
- **키워드 매칭 규칙**:
  - 축제명(`title`) 정규식 매칭: `뮤직|락|재즈|콘서트|페스티벌|음악|버스킹|비어|맥주`
- **노출 구성 및 정렬**:
  1. **진행 중 축제**: 키워드 매칭 축제 중 `start_date DESC` 정렬 최대 6건.
  2. **진행 예정 축제**: 키워드 매칭 축제 중 `start_date ASC` (D-Day 임박순) 최대 8건.
  3. 진행 중 축제 선배치 후 진행 예정 축제를 순차 결합하여 노출함.

### 4.4. 테마 3: [낭만 가득 야간 & 빛 축제]
- **기획 목적**: 야간개장, 불꽃, 드론쇼, 달빛 야행 등 야간 시간대 특화 축제 선별 제공.
- **키워드 매칭 규칙**:
  - 축제명(`title`) 정규식 매칭: `야간|빛|불꽃|달빛|밤|나이트|드론`
- **노출 구성 및 정렬**:
  1. **진행 중 축제**: 키워드 매칭 축제 중 `start_date DESC` 정렬 최대 6건.
  2. **진행 예정 축제**: 키워드 매칭 축제 중 `start_date ASC` (D-Day 임박순) 최대 8건.
  3. 진행 중 축제 선배치 후 진행 예정 축제를 순차 결합하여 노출함.

### 4.5. 테마 4: [온 가족 & 아이와 함께 가기 좋은 축제]
- **기획 목적**: 어린이, 체험, 캐릭터, 생태, 가족 단위 방문에 적합한 교육·체험형 축제 선별 제공.
- **키워드 매칭 규칙**:
  - 축제명(`title`) 정규식 매칭: `어린이|가족|만화|체험|공룡|인형|생태|키즈`
  - 본문 개요(`overview`) 보조 매칭: 축제명에 키워드가 없더라도 소개 본문에 `가족|어린이|체험` 단어가 포함된 경우 대상에 포함함.
- **노출 구성 및 정렬**:
  1. **진행 중 축제**: 매칭 축제 중 `start_date DESC` 정렬 최대 6건.
  2. **진행 예정 축제**: 매칭 축제 중 `start_date ASC` (D-Day 임박순) 최대 8건.
  3. 진행 중 축제 선배치 후 진행 예정 축제를 순차 결합하여 노출함.

## 5. 축제 상세 화면 구성 사양

### 5.1. 상단 비주얼 영역 (대표 포스터)
- **포스터 노출 기준**:
  - 세로형 포스터 원본이 상하 잘림 없이 온전하게 노출되도록 비율(`object-contain`)을 유지함.
  - 좌우 여백 영역을 자연스러운 배경색으로 마감 처리함.
- **내비게이션 기능**: 이전 목록으로 이동하는 '뒤로가기' 버튼 및 현재 페이지 URL을 복사하는 '공유하기' 버튼을 제공함.

### 5.2. 헤더 정보 영역
- **진행 상태 뱃지**: `진행 중`, `D-Day / D-N (진행 예정)`, `종료된 축제` 3단계로 구분하여 노출함.
- **축제명**: 축제명을 강조 표출함.

### 5.3. 핵심 메타 정보 영역
- **개최 기간**: 시작일 및 종료일을 표기함.
- **개최 장소**: 도로명 주소를 기본 표기함.
- **이용 요금**: 무료 또는 유료 세부 요금 정보를 표기함.
- **관람 소요 시간**: 데이터가 존재하는 경우 표기함.
- **문의처**: 대표 전화번호를 표기하고 모바일 환경에서 터치 시 전화 걸기 기능을 지원함.

### 5.4. 축제 소개 모듈
- 축제 개요 및 상세 취지 소개글을 표출함.
- **모듈 영역 유지 정책**: 등록된 소개 데이터가 없는 경우에도 모듈 박스 영역을 유지하며, `"상세 축제 소개 정보가 준비 중입니다."` 안내 문구를 표출함.
- 주최 및 주관 기관 정보가 존재하는 경우 하단에 함께 표기함.

### 5.5. 주요 행사 프로그램 모듈
- 주요 공연, 퍼레이드, 무대 행사 등 일정표 데이터를 표출함.
- **모듈 영역 유지 정책**: 등록된 프로그램 데이터가 없는 경우에도 모듈 박스 영역을 유지하며, `"등록된 주요 행사 프로그램 정보가 없습니다. 상세 일정은 공식 홈페이지를 참고해주세요."` 안내 문구를 표출함.

### 5.6. 부대행사 및 특별 프로그램 모듈
- 부대행사, 상설 체험 프로그램, 이벤트 안내 텍스트를 표출함.
- **모듈 영역 유지 정책**: 등록된 부대행사 데이터가 없는 경우에도 모듈 박스 영역을 유지하며, `"등록된 부대행사 및 특별 프로그램 정보가 없습니다."` 안내 문구를 표출함.

### 5.7. 축제 현장 갤러리 모듈
- **노출 위치**: 축제 소개, 주요 행사 프로그램, 부대행사 모듈 하단에 배치함.
- **기능 사양**:
  - 한국관광공사 TourAPI의 서브 이미지 데이터를 연동하여 사진 목록을 표출함.
  - 사진 선택 시 화면 전체를 활용한 사진 확대 뷰어를 제공하며, 이전/다음 사진 탐색 기능을 지원함.

### 5.8. 공식 홈페이지 바로가기
- 공식 웹사이트 주소 데이터가 존재하는 경우 외부 새 창으로 연결되는 버튼을 제공함.

## 6. 운영 관리자 화면 및 정책

### 6.1. 관리자 개요
- 등록된 축제 데이터의 노출 상태를 제어하고, 공공 API에 미반영된 축제를 수동 등록하는 관리 기능을 제공함.

### 6.2. 축제 목록 관리
- **목록 항목**: 번호, 축제명(선택 시 상세 미리보기), 개최 기간, 개최 지역, 데이터 출처(API 수집 / 수동 등록), 공개 상태.
- **공개 상태 제어**:
  - 축제별로 `공개 중` / `숨김` 상태를 즉시 전환할 수 있는 기능을 제공함.
  - `숨김` 처리된 축제는 사용자 화면(지도, 검색, 큐레이션)에서 즉시 제외됨.

### 6.3. 신규 축제 수동 등록
- 관리자가 축제명, 행사 기간, 개최 장소, 좌표, 대표 이미지 주소, 이용 요금, 운영 시간, 상세 소개글을 직접 입력하여 데이터베이스에 신규 등록할 수 있는 입력 양식을 제공함.

## 7. 시스템 및 데이터 정책

### 7.1. 기준 일자 관리 정책 (`SERVICE_TODAY`)
- 서비스 기준 일자를 단일 상수로 정의하여 메인 화면 필터, 큐레이션 연산, 상세 화면 상태 판별 시 전역에서 일관되게 참조함.

### 7.2. 데이터베이스 연결 관리
- 서버리스 환경에서 데이터베이스 연결 자원을 효율적으로 관리하기 위해 데이터베이스 연결 인스턴스를 단일화하여 재사용함.

### 7.3. 예외 처리 정책
- **존재하지 않는 축제 ID 접근 시**: 표준 안내 화면(404 Not Found)을 표출함.
- **지도 마커 연동 오류 방지**: 마커 팝업 및 상세 화면 이동 이벤트 간 간섭을 분리하여 안정적인 페이지 전환을 보장함.
