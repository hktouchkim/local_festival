# 한경 지역축제 서비스 기획 정의서

본 문서는 한경 트래블 하위 신규 서비스인 '한경 지역축제'의 화면 구조, 기능 사양, 정책 및 데이터 연동 기준을 기술함. 디자이너, 퍼블리셔, 개발자가 즉시 구축 가능한 수준으로 화면과 정책 중심으로 서술함.

---

## 1. 서비스 개요

### 1.1. 서비스 목적
- 전국 각지의 축제 정보를 지도 및 목록 형태로 직관적으로 제공하여 주말 나들이 및 국내여행 탐색 편의성 제공.
- 공공 데이터(한국관광공사 TourAPI)를 가공·축적하여 한경 트래블만의 독자적 축제 콘텐츠 플랫폼 구축.

### 1.2. 기본 운영 원칙
- **일일 1회 배치(DB 적재) 운영**: 한국관광공사 TourAPI 데이터를 하루 1회 전건 동기화하여 자체 DB로 운영(사용자 접속 시 실시간 외부 API 호출 배제).
- **상세 완결형 서비스**: 목록 API뿐만 아니라 상세 API까지 DB에 일괄 적재하여 외부 사이트 이탈 없이 한경 서비스 내에서 축제 개요, 이용요금, 운영시간, 상세 소개까지 완결형으로 제공.
- **반응형 웹 지원**: PC 웹과 모바일 웹 환경을 모두 지원하며, 모바일은 지도-바텀시트 하이브리드 인터랙션 제공.
- **브랜드 일관성**: 한경 공식 네이비 계열 색상을 메인 포인트 컬러로 사용.

---

## 2. 진입 경로 및 메뉴 변경 정책

### 2.1. 상단 메뉴(GNB) 개편
- **기존 한경 트래블 GNB 변경**:
  - `커뮤니티`, `검색` 2개 메뉴 항목 삭제.
  - 삭제된 위치에 `지역축제` 신규 메뉴 항목 추가.
- **연결 대상**: `지역축제` 메뉴 클릭 시 한경 지역축제 메인 화면으로 이동.
- **공통 영역 유지**:
  - 상단 패밀리 헤더, 한경 로고, 로그인, My한경 등 공통 요소는 원본 규격 유지.
  - 삭제되는 `검색`은 한경 트래블 GNB 내 메뉴 항목에 한하며, 한경 전사 통합 검색 기능 삭제가 아님.

## 3. 사용자 이용 흐름

```
[한경 트래블 GNB]
       │
       ▼ ('지역축제' 클릭)
[지역축제 메인 화면]
       │
       ├─► 필터/검색 적용 (축제명 검색, 지역 선택, 기간 선택, 진행 상태 탭)
       │
       ├─► [PC 웹 환경]
       │       ├─► 좌측 지도 마커 선택 ──► 우측 목록 스크롤 이동 및 강조
       │       └─► 우측 목록 카드 탐색 ──► 지도 마커 포커싱
       │
       ├─► [모바일 웹 환경]
       │       ├─► 메인: 목록 중심 탐색
       │       └─► '지도로 보기' 선택 시 ──► 전체 지도 + 하단 바텀시트 모드 전환
       │
       └─► [축제 카드 선택]
               │
               ▼
       [축제 상세 화면] (자체 화면 이동)
       - 행사 개요, 기간, 장소(지도 마커 연동)
       - 행사 운영시간, 이용요금, 주최/주관사
       - 상세 행사 소개글 및 공식 홈페이지 바로가기 링크
```

## 4. 화면 및 기능 상세 정의

### 4.1. 공통 검색 및 필터 정책
- **4.1.1. 축제명 검색**:
  - 입력창 형태, 플레이스홀더: `축제명을 입력해주세요`.
  - 엔터 또는 돋보기 아이콘 클릭 시 검색 실행.
  - 한 글자 이상 입력 시 검색 가능, 특수문자 입력 제한 없음.
- **4.1.2. 기간 필터 (다중 선택/직접 설정)**:
  - **빠른 탭**: `전체`, `진행 중인 축제`, `이번 주말`, `이번 달`.
  - **직접 설정**: 시작일(Datepicker) ~ 종료일(Datepicker).
  - **기간 판정 로직 (겹침 기준)**:
    - `축제 시작일 <= 검색 종료일` AND `축제 종료일 >= 검색 시작일` 조건 충족 시 결과 노출.
    - 검색 기간과 축제 기간이 1일이라도 겹치면 노출 대상에 포함.
- **4.1.3. 지역 필터**:
  - 광역시·도 단위 드롭다운 또는 버튼 선택: `전국`, `서울`, `경기/인천`, `강원`, `충청/대전/세종`, `전라/광주`, `경상/부산/대구/울산`, `제주`.
  - 지역 선택 시 해당 지역 DB 데이터만 필터링하여 지도 좌표 이동 및 목록 갱신.
- **4.1.4. 초기 진입값**:
  - 지역: `전국`.
  - 기간: `진행 중인 축제` (금일 기준 현재 진행 중인 축제를 기본 정렬하여 즉시성 확보).
  - 정렬: `종료 임박순` 또는 `시작일 최신순`.

---

### 4.2. PC 웹 화면 구성

- **화면 분할 구조 (2단 레이아웃)**:
  - 상단: 한경 공통 헤더 + 트래블 GNB + 지역/기간/검색 필터 바.
  - 본문 좌측(50~60%): 인터랙티브 대한민국 지도 영역 (화면 스크롤 시 화면 높이에 맞춰 고정 가능).
  - 본문 우측(40~50%): 축제 카드 목록 (무한 스크롤 또는 페이징).
- **지도-목록 상호작용**:
  - **지도 마커 클릭 시**: 
    - 우측 목록에서 해당 축제 카드로 자동 스크롤(스크롤 애니메이션 적용).
    - 해당 카드 외곽선 한경 네이비 색상으로 1~2초간 하이라이트 표시.
    - 지도 중심을 해당 마커 좌표로 이동.
  - **목록 카드 호버/클릭 시**:
    - 지도 상의 대응 마커가 활성 상태(크기 확대 및 핀 색상 변경)로 전환.
    - 마커 상단에 미니 말풍선(축제명 표기) 자동 노출.
  - **지도 클러스터링**:
    - 동일 지역에 다수 축제 밀집 시 건수 숫자 뱃지가 표시되는 원형 클러스터 마커 노출.
    - 클러스터 클릭 시 지도 확대 레벨이 한 단계 증가하며 개별 마커 분기.

---

### 4.3. 모바일 웹 화면 구성 (하이브리드 바텀시트 방식)

- **4.3.1. 기본 화면 (목록 뷰)**:
  - 상단: 트래블 GNB 및 접이식 검색/필터 바.
  - 중단: 조건에 맞는 축제 카드 세로 1열 리스트.
  - 하단 우측 플로팅 버튼: `지도로 보기` (지도 아이콘 + 한경 네이비 둥근 버튼 고정).
- **4.3.2. 지도 탐색 화면 (바텀시트 모드)**:
  - `지도로 보기` 터치 시 지도 전용 모드로 전환.
  - 상단: 뒤로가기 버튼 + 핵심 필터 축약 태그(선택 지역, 날짜).
  - 본문 배경: 모바일 전체 화면 지도.
  - 하단 바텀시트 (3단계 높이 조절 인터랙션):
    - **1단계 (접힘 상태, 기본)**: 현재 선택된 축제 카드 1건만 요약 노출(대표 이미지, 축제명, 기간, 주소).
    - **2단계 (반 확장 상태)**: 바텀시트 핸들을 위로 스와이프 시 화면의 절반 높이로 확장되어 축제 목록 2~3건 노출.
    - **3단계 (전체 확장 상태)**: 상단 끝까지 올리면 전체 목록 화면으로 전환.
    - **지도 복귀**: 바텀시트를 아래로 내리면 다시 1단계로 접히며 지도 탐색에 집중 가능.
  - 우측 하단 플로팅 버튼: `목록으로 보기` 터치 시 최초 목록 뷰로 복귀.

---

### 4.4. 축제 카드(컴포넌트) 구성 사양

- **카드 필수 표기 요소**:
  1. **대표 이미지**: 4:3 또는 16:9 비율 썸네일.
  2. **진행 상태 뱃지**: `진행 중`(네이비), `개최 예정`(그레이), `오늘 종료`(레드).
  3. **축제명**: 최대 2줄 노출 후 말줄임(`...`) 처리.
  4. **행사 기간**: `YYYY.MM.DD ~ YYYY.MM.DD` 포맷.
  5. **개최 지역/주소**: 시·군·구 단위 또는 기본 도로명 주소(`addr1`).
  6. **북마크/공유 버튼 (선택 사항)**: URL 복사 기능.
- **카드 인터랙션**:
  - 카드 전체 영역 탭/클릭 시 해당 축제의 **자체 상세 화면**으로 라우팅.

---

### 4.5. 축제 상세 화면 구성 사양

- **화면 구조**:
  - **상단 비주얼 영역**: 고화질 대표 이미지 와이드 노출, 뒤로가기, 공유하기 버튼.
  - **헤더 타이틀 영역**: 진행 상태 뱃지, 축제명, 조회수/등록일.
  - **핵심 메타 정보 박스 (아이콘 + 텍스트)**:
    - 행사 기간: 시작일 ~ 종료일 표기 및 D-Day 표기.
    - 관람/운영 시간: 수신된 행사 시간 텍스트 노출.
    - 행사장 위치: 도로명 주소 + 지번 주소 + `지도 복사` 버튼.
    - 이용 요금: 무료 / 유료 및 세부 금액 텍스트.
    - 문의처/전화번호: 모바일 환경에서 터치 시 즉시 전화걸기(`tel:`) 연결.
    - 주최/주관사 정보: 주최기관 및 주관기관 텍스트 표기.
  - **축제 소개 본문**: 행사 내용, 프로그램 설명, 부대행사 텍스트 서술.
  - **행사장 위치 지도 (단건 지도 뷰)**:
    - 상세 화면 내 정적/동적 지도 1건 삽입, 행사장 정중앙 마커 표시.
    - 길찾기 연동(카카오맵/네이버지도 길찾기 외부 링크 연결 옵션).
  - **공식 링크 연결**:
    - '공식 홈페이지 바로가기' 아웃링크 버튼 배치(새 창 열림, 외부 도메인 이동).

## 5. 데이터 연동 및 관리 정책

### 5.1. 배치 동기화 정책
- **주기**: 매일 1회 정기 실행 (새벽 03:00~04:00 권장 트래픽 최소 시간대).
- **동기화 범위**:
  - 과거 종료된 지 30일 초과 축제는 수집 대상에서 제외하거나 비활성화 처리.
  - 현재 시점 기준 `진행 예정` 및 `진행 중` 축제를 집중 동기화.
- **동기화 파이프라인**:
  1. `searchFestival2`를 통해 전국 축제 기본 목록 수신 (기본 메타 및 `contentid` 취득).
  2. 신규 등록 및 수정된 축제 건에 대해 상세 API(`detailCommon2`, `detailIntro2`) 순차 호출.
  3. 자체 축제 DB 테이블에 완전 병합(Upsert).
  4. 주간/일간 단위 삭제 및 비노출 축제 상태 갱신.

### 5.2. 화면 필드별 API 데이터 출처 정의

| 화면 영역 | 노출 항목 | 데이터 소스 (API) | 세부 필드명 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **목록/카드** | 축제 고유 식별자 | `searchFestival2` | `contentid` | 내부 상세 화면 매핑 키 |
| **목록/카드** | 축제명 | `searchFestival2` | `title` | 특수문자 HTML 디코딩 필요 |
| **목록/카드** | 시작일/종료일 | `searchFestival2` | `eventstartdate`, `eventenddate` | YYYYMMDD -> YYYY.MM.DD 포맷팅 |
| **목록/카드** | 대표 이미지 | `searchFestival2` | `firstimage` (대체: `firstimage2`) | 결측 시 디폴트 이미지 노출 |
| **목록/카드** | 주소 | `searchFestival2` | `addr1`, `addr2` | 도로명 또는 지번 주소 |
| **목록/카드** | 지도 좌표 | `searchFestival2` | `mapx` (경도), `mapy` (위도) | 마커 표기용 |
| **상세 화면** | 상세 소개 개요 | `detailCommon2` | `overview` | 장문 텍스트 (줄바꿈 처리) |
| **상세 화면** | 공식 홈페이지 링크 | `detailCommon2` | `homepage` | HTML 태그 정제 후 URL 추출 |
| **상세 화면** | 행사 운영시간 | `detailIntro2` | `playtime` | 텍스트 노출 |
| **상세 화면** | 행사 이용요금 | `detailIntro2` | `usetimefestival` | 무료/유료 및 요금표 텍스트 |
| **상세 화면** | 주최/주관 기관 | `detailIntro2` | `sponsor1`, `sponsor2` | 주최사 표기 |
| **상세 화면** | 상세 프로그램 | `detailIntro2` | `program` | 세부 일정 및 행사 구성 |

## 6. 예외 상황 처리 정책

### 6.1. 대표 이미지 누락 건
- API 응답값 상 `firstimage` 및 `firstimage2`가 빈 값인 경우:
  - 기획 및 디자인에서 사전에 정의한 **한경 지역축제 기본 대체 이미지(디폴트 그래픽)** 강제 적용.
  - 카드의 레이아웃 깨짐 없이 규격(비율) 동일 유지.
  - 목록에서 임의 제외하지 않고 정상 노출.

### 6.2. 좌표 데이터 누락 건 (`mapx`, `mapy` 없음)
- 위경도 값이 없거나 0인 경우:
  - 지도 영역 상에는 마커를 생성하지 않음.
  - 우측 목록 카드에는 정상 노출하되, 주소란에 '지도 위치 미제공' 표기.
  - 상세 화면 이동 시 지도 뷰 대신 '위치 정보 준비 중' 안내 박스 노출.

### 6.3. 검색 결과 없음 (Empty State)
- 검색어 또는 필터 조건에 부합하는 축제가 0건일 때:
  - 지도: 해당 지역 중심 좌표로 이동하되 마커 노출 없음.
  - 목록: 카드 리스트 영역 중앙에 안내 아이콘 노출.
  - 문구: `"조건에 맞는 지역축제가 없습니다. 검색어 또는 기간 설정을 변경해주세요."` 노출.
  - 하단에 `전체 축제 보기` 초기화 버튼 제공.

### 6.4. 통신/시스템 오류 (Error State)
- 일시적 통신 실패 또는 데이터 조회 실패 시:
  - 네트워크 재시도 버튼이 포함된 에러 컴포넌트 노출.
  - 안내 문구: `"축제 정보를 불러오는 중 일시적인 오류가 발생했습니다. 잠시 후 다시 시도해주세요."`

## 7. 운영 관리자(어드민) 화면 및 기능 정의

### 7.1. 관리자 개요
- **목적**: 등록된 축제 데이터의 노출 상태(공개/숨김) 제어 및 공공 API 미반영 자체/제휴 축제 신규 등록.
- **수정 정책**: 축제 정보의 직접 수정은 불가함 (동기화 정합성 및 운영 단순화 목적). 수정 필요 시 '숨김' 처리 후 새로 등록하거나 다음 일일 배치 데이터 갱신을 통해 처리함.

### 7.2. 축제 관리 목록 화면
- **목록 표기 항목**:
  1. No (순번)
  2. 축제명 (클릭 시 사용자 화면 상세 미리보기 새 창 열림)
  3. 개최 기간 (시작일 ~ 종료일)
  4. 개최 지역 (시·도)
  5. 데이터 출처 (TourAPI 자동수집 / 관리자 수동등록)
  6. 등록일시
  7. **공개 상태 토글 스위치 (공개 / 숨김)**
- **상태 제어 정책**:
  - `공개(ON)`: 사용자 화면(지도/목록/검색)에 정상 노출.
  - `숨김(OFF)`: 사용자 화면의 모든 영역에서 즉시 제외 처리 (DB에는 유지).
  - 관리자가 토글 스위치 조작 시 확인 팝업(`"상태를 변경하시겠습니까?"`) 노출 후 '확인' 클릭 시 즉시 반영.
- **필터 및 검색**:
  - 공개 상태 필터 (`전체`, `공개`, `숨김`).
  - 데이터 출처 필터 (`전체`, `API 수집`, `수동 등록`).
  - 축제명 검색창.
- **페이징**: 페이지당 20건 기본 노출.

### 7.3. 축제 수동 등록 화면
- **등록 방식**: 관리자가 직접 모든 필수/선택 정보를 입력하여 단건 생성.
- **입력 항목 사양**:
  - **축제명 (필수)**: 텍스트 입력 (최대 100자).
  - **행사 기간 (필수)**: 시작일(Datepicker) 및 종료일(Datepicker).
  - **개최 장소 (필수)**:
    - 기본 주소(도로명/지번) 및 상세 주소 텍스트 입력.
    - 지도 위경도 좌표: 주소 입력 시 지오코딩 자동 변환 또는 지도 핀 클릭 선택.
  - **대표 이미지 (선택)**: 이미지 파일 직접 업로드(최대 5MB, JPG/PNG) 또는 이미지 URL 입력 (미입력 시 기본 디폴트 이미지 적용).
  - **행사 운영시간 (선택)**: 텍스트 입력 (예: 10:00 ~ 18:00).
  - **이용 요금 (선택)**: 텍스트 입력 (예: 무료 또는 유료 세부 금액).
  - **주최/주관 기관 (선택)**: 텍스트 입력.
  - **문의 전화번호 (선택)**: 숫자 및 하이픈 텍스트 입력.
  - **공식 홈페이지 링크 (선택)**: 웹 URL 형식 입력.
  - **축제 상세 소개 (필수)**: 텍스트에어리어 (장문 줄바꿈 지원).
- **저장 처리**:
  - '등록' 버튼 클릭 시 유효성 검증(필수값 누락 체크).
  - 성공 시: DB 적재(출처: `MANUAL`, 공개상태: `공개` 기본값) 완료 후 관리자 목록 첫 페이지로 이동 및 안내 메시지 노출.

## 8. 담당 파트별 확인 및 협조 사항

### 8.1. 디자이너 확인사항
- 한경 네이비(Navy) 아이덴티티를 반영한 지도 마커 핀 디자인 (기본 핀, 활성 핀, 클러스터 핀 3종).
- 대표 이미지 미제공 축제에 적용할 한경 전용 디폴트 그래픽 제작(4:3 및 16:9 대응).
- 모바일 바텀시트 3단계 높이(접힘/반확장/전체) UI 가이드 및 스와이프 핸들 바 디자인.
- 진행 상태 뱃지 3종(진행 중, 개최 예정, 오늘 종료) 색상 셋 정의.
- 관리자 화면 UI 레이아웃 및 공개/숨김 토글 스위치 컴포넌트 디자인.

### 8.2. 퍼블리셔 확인사항
- 모바일 환경 터치 제스처 구현 (지도 패닝 터치와 하단 바텀시트 수직 스크롤 간섭 방지 처리).
- PC 2단 분할 레이아웃 시 좌측 지도 영역 뷰포트 고정(Sticky/Fixed) 퍼블리싱.
- 목록 카드와 지도 간 마커 호버/클릭 시 애니메이션 효과(트랜지션) 적용.

### 8.3. 개발 파트 확인사항
- **일일 1회 배치 스케줄러 구축**: 한국관광공사 TourAPI 트래픽 제한(초당 요청 수 등)을 준수하며 `searchFestival2` -> `detailCommon2`, `detailIntro2` 순차 호출 및 자체 DB 적재 로직 구현.
- **관리자 기능 구현**: 축제 테이블 내 `status`(공개: `PUBLISHED`, 숨김: `HIDDEN`) 및 `source`(API: `API`, 수동: `MANUAL`) 컬럼 추가, 상태 업데이트 API 및 수동 등록 API 구현.
- **날짜 필터 쿼리 최적화**: 축제 기간과 검색 조건 간 겹침 연산(`eventstartdate <= End` AND `eventenddate >= Start` AND `status = 'PUBLISHED'`) 인덱싱 처리.
- **지도 라이브러리 연동**: 네이버 지도 또는 카카오맵 웹 SDK 마커 클러스터링 모듈 적용.
- **데이터 정제**: API 수신값 내 HTML 엔티티(`&lt;`, `&gt;`, `&amp;` 등) 디코딩 및 불필요한 태그 파싱 처리.

## 9. 확정 및 미확정 사항 정리

### 9.1. 확정 사항
- 서비스 명칭('한경 지역축제') 및 한경 트래블 하위 편입.
- 트래블 GNB 개편(`커뮤니티`, `검색` 삭제 -> `지역축제` 추가).
- 데이터베이스 자체 적재 및 일 1회 TourAPI 배치 동기화 구조 채택.
- 상세 API(`detailCommon2`, `detailIntro2`)까지 일괄 수집하여 내부 완결형 상세 화면 구축.
- 이미지 결측 건 대상 한경 전용 디폴트 이미지 노출.
- 모바일 환경 지도-바텀시트 하이브리드 연동 탐색 채택.
- **운영 관리자 기능 확정**: 전체 축제 목록 조회, 상태값 제어(공개/숨김), 모든 항목 직접 입력을 통한 수동 등록 기능 구축 (직접 수정 기능은 제외).

### 9.2. 향후 검토 과제 (차기 고도화)
- 축제 찜하기(북마크) 및 My한경 연동 보관함 기능.
- 카카오톡/SNS 축제 링크 공유 시 오픈그래프(OG) 동적 썸네일 생성.
- 날씨 API 연동을 통한 축제 개최지 주말 날씨 예보 부가 정보 제공.
