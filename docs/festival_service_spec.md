# 지역축제 서비스 기능 및 정책 정의서

본 문서는 전국 지역축제 인터랙티브 지도 서비스의 목적, 화면 구성 체계, 사용자 기능, 화면 전환 및 데이터 정책을 기술함.

---

## 1. 서비스 개요

### 1.1. 목적 및 대상
- **목적**: 전국 각지의 지역축제 정보를 지도 중심의 직관적인 인터랙션을 통해 쉽게 탐색하고 상세 정보를 열람할 수 있는 플랫폼을 제공함.
- **주요 대상**: 주말 여행객, 가족 단위 나들이객, 지역 문화행사 탐색자.
- **제공 환경**: 반응형 웹 (PC 및 모바일 웹 브라우저 지원).

### 1.2. 화면 및 운영 기본 정책
- **단일 화면 완결형 구조**: 불필요한 하단 스크롤을 배제하고 상단 헤더, 풀스크린 지도, 탐색 패널의 유기적 결합을 통해 한 화면 내에서 탐색을 완결함.
- **데이터 갱신 주기**: 공공데이터 기반 1일 1회 정기 갱신을 통해 최신 정보를 유지함.

### 1.3. 지도 개발 사양 및 핵심 구현 지침
- **프로토타입 환경**: 기능 검증 및 사용성 테스트 목적으로 카카오 지도 기반으로 구축함.
- **상용 서비스 개발 지침 (필수 준수 사항)**:
  - **상용 서비스 개발 시에는 한국경제 닷컴 표준 환경에 맞추어 네이버 지도(Naver Maps API)로 전환 개발함.**
  - 프로토타입에서 정의된 화면 좌표 영역 필터링, 부드러운 화면 이동, 축척 제어, 마커 그룹화(클러스터링), 반응형 중심점 보정 정책을 네이버 지도 기능으로 동일하게 구현함.

### 1.4. 한경 트래블 사이트 연동 및 서브메뉴 개편 정책
- **상단 서브메뉴 개편 사항**:
  - 기존 서브메뉴 중 **커뮤니티** 및 **검색** 메뉴는 서비스 정리 정책에 따라 삭제함.
  - 서브메뉴 **우측 끝 위치에 `지역축제` 신규 메뉴 버튼을 신설**하여 주요 진입점으로 연결함.
- **진입점 동작 정책**:
  - 메뉴 클릭 시 지역축제 지도 화면으로 즉시 연결됨.
  - 최초 진입 시 에디터 추천 축제(한경 트래블 PICK)가 기본 노출되도록 구성함.

## 2. 화면 구조 및 사용자 인터페이스(UI) 구성

### 2.1. 상단 헤더
- **화면 배치**: 최상단 고정 노출.
- **구성 요소**:
  - 브랜드 로고 및 서비스 명칭 표기 (`지역축제`).
  - 지도 화면 영역을 최대로 확보하기 위해 로그인 및 기타 부가 메뉴는 배제함.

### 2.2. 메인 지도 화면
- **화면 점유**: 헤더를 제외한 화면 전체 영역을 채움.
- **지도 컨트롤 및 탐색**:
  - **내 위치 찾기 버튼**: 우측 하단에 배치하며, 클릭 시 기기 GPS 기반으로 현재 위치로 지도 중심을 이동함.
  - **마커 표기**: 축제의 진행 상태별로 마커 색상을 구분 표기하며, 밀집 지역은 숫자로 묶어 표시하는 클러스터링을 적용함.
  - **현 지도에서 검색 버튼**: 사용자가 지도를 직접 드래그하거나 확대/축소했을 때만 화면 상단에 플로팅 노출하여, 클릭 시 현재 보이는 지도 범위 내 축제만 목록에 갱신함.

### 2.3. 검색 및 탐색 패널
- **화면 점유**: PC 환경은 좌측 상시 고정 패널로 배치하며, 모바일 환경은 하단 서랍형 바텀시트로 구성함.
- **PC 지도 중심축 시야 보정**: PC에서는 좌측 패널 너비로 인해 한반도 지도가 치우쳐 보이지 않도록 중심점을 보정하여 우측 가시 영역 중앙에 안정적으로 위치하도록 함.
- **패널 내부 UI 구성 순서**:
  1. **통합 검색창**:
     - 축제명 또는 지역명(시/군/구) 입력 검색 지원.
     - 검색어 입력 시 노출되는 삭제(X) 버튼 클릭 시, 검색어 지움과 동시에 필터 및 지도 화면이 초기 기본 상태로 리셋됨.
     - 상세 공유 링크로 유입된 경우에도 삭제(X) 버튼을 누르면 주소창 파라미터가 정리되며 기본 전국 화면으로 복귀함.
  2. **추천 테마 배너**:
     - 상단에 추천 테마를 롤링 배너 형태로 노출하여 직관적인 테마 탐색 유도.
     - 주목도가 높은 밝고 화사한 색상톤 적용.
     - 서브 카피: `에디터가 엄선한 실패 없는 전국 대표 축제`
     - 배너 클릭 시 해당 테마에 부합하는 축제 목록이 노출되며, 반복 클릭해도 목록 상태를 안정적으로 유지함.
  3. **검색 결과 안내 문구**: 현재 조건에 해당하는 축제 건수를 명확한 문장(`총 OO개의 축제가 있습니다.`)으로 안내.
  4. **진행 상태 필터 (체크박스 토글)**:
     - `진행중`, `예정`, `종료` 상태를 사용자가 자유롭게 조합하여 볼 수 있도록 다중 선택 필터 제공.
  5. **축제 목록 피드 및 일정순 정렬**:
     - 현재 지도 범위 및 선택 필터에 부합하는 축제 카드를 목록으로 제공.
     - 카드 전체를 터치 영역으로 구성하여 간결하게 상세 화면으로 연결.
     - **정렬 우선순위**:
       - 1순위: 현재 방문 가능한 **진행 중 축제** 최우선 노출 (종료 마감일 임박순).
       - 2순위: 곧 방문 가능한 **진행 예정 축제** 차순위 노출 (개막일 임박순).
       - 3순위: 이미 끝난 **종료 축제** 최하단 노출 (최근 종료일순).

### 2.4. 축제 상세 정보 패널
- **노출 시점**: 목록 카드 클릭 또는 지도 상의 개별 마커 클릭 시 즉시 노출.
- **배치 형태**: PC에서는 좌측 검색 패널 우측에 나란히 플로팅 노출되며, 모바일에서는 화면을 채우는 바텀시트 모달로 노출됨.
- **스크롤 초기화 정책**: 상세 패널이 열려 있는 상태에서 다른 축제를 연속으로 선택하더라도, 이전 축제의 스크롤 잔류 없이 항상 상세 화면의 맨 위부터 표시되도록 함.
- **상세 패널 내부 구성**:
  - 대표 이미지: 원본 비율을 보존하여 노출하며, 터치 시 크게 볼 수 있는 확대 보기 지원.
  - 기본 정보: 축제명, 진행 상태, 행사 기간, 도로명/지번 주소, 전화번호, 공식 홈페이지 바로가기 링크.
  - 행사 개요 및 소개 본문.
  - 길찾기 지원: 주요 지도 앱(네이버지도, 카카오맵)과 연동되는 원클릭 길찾기 아웃링크 제공.
  - 현장 갤러리 피드: 현장감을 느낄 수 있는 사진들을 아래로 시원하게 볼 수 있는 피드 형태로 배치.
  - 상단 닫기(X) 버튼 지원.

### 2.5. 모바일 전용 사용자 인터페이스(UI) 정책
- **모바일 첫 진입 지도 시야 최적화 정책**:
  - 모바일 첫 진입 시 하단 서랍형 바텀시트에 의해 남부 지방이나 제주도가 가려지지 않도록 초기 지도 축척을 넓게 조정하고 중심점을 남쪽으로 보정하여, 사용자가 조작하지 않아도 한반도 전역의 주요 축제가 첫 화면에 시원하게 들어오도록 함.
- **서랍형 바텀시트 인터랙션**:
  - **접힘 상태**: 지도 시야를 극대화하기 위해 검색창 영역만 하단에 콤팩트하게 노출.
  - **펼침 상태**: 중앙 핸들바를 위로 밀어 올리거나 검색창을 터치하면 화면 대부분을 덮는 풀스크린 형태로 부드럽게 확장되어 추천 배너, 필터, 축제 목록을 탐색할 수 있도록 함.
  - **스크롤 제스처 분리**: 목록 스크롤이 맨 위에 닿은 상태에서만 바텀시트를 아래로 닫을 수 있도록 제스처를 분리하여 사용성을 보호함.
- **모바일 상세화면 인터랙션**:
  - 모바일에서 축제 선택 시 전체 화면을 시원하게 채우는 풀사이즈 시트로 전환되며, 핸들바를 아래로 쓸어내려 손쉽게 닫고 이전 탐색 화면으로 복귀 가능함.

## 3. 기능 및 데이터 연동 정책

### 3.1. 기본 진입 화면 및 테마 검색 연동
- **기본 진입 상태**: 사용자가 처음 접속 시 **'한경 트래블 PICK'**이 기본 선택되어 첫 화면부터 풍부한 대표 축제 목록을 제공함.
- **추천 테마 선별 조건**:
  - `한경 트래블 PICK`: 축제 소개글 또는 행사 프로그램 설명이 충실히 등록되어 있고, 현장 사진이 최소 1장 이상 등록된 현재 진행 중 또는 예정인 대표 축제만을 엄선하여 노출.
  - `뮤직 & 페스티벌`: 대중음악, 락, 재즈, 콘서트, 버스킹, 맥주 관련 축제 자동 연동.
  - `야간 & 빛 축제`: 야간 개장, 빛, 불꽃, 달빛, 밤, 나이트, 드론 관련 축제 자동 연동.

### 3.2. 상태 필터 및 종료 축제 조회 제한
- **기본 선택 상태**: `진행 중(선택)`, `진행 예정(선택)`, `종료(미선택)`.
- **종료 축제 조회 기간 제한 정책 (성능 및 데이터 과부하 방지)**:
  - '종료' 축제는 최근 1년 이내에 종료된 축제까지만 한정 노출함.
  - 1년이 지난 과거 데이터는 목록 및 지도에서 제외하여 화면 렌더링 부하 및 탐색 피로도를 방지함.

### 3.3. 지도-목록 연동 및 카메라 이동 정책
- **목록 선택 시 지도 연동**: 목록에서 특정 축제를 선택하면 해당 위치로 부드럽게 글라이딩 이동함. 이때 패널에 마커가 가려지지 않도록 시야를 고려한 중심점에 포커싱하며, 시스템 이동 시에는 '현 지도에서 검색' 버튼을 띄우지 않음.
- **사용자 지도 조작 시 연동**: 사용자가 직접 지도를 움직이거나 줌을 변경한 경우에만 '현 지도에서 검색' 버튼을 노출하여 사용자 의도에 따라 현재 영역의 축제 목록을 갱신함.

## 4. 예외 상황 처리 및 사용자 안내 정책

1. **검색 결과 0건 시**:
   - 안내 문구: "검색 조건에 맞는 축제가 없습니다. 지도를 다른 지역으로 이동해보세요."
   - 조치 권유: 검색어 초기화 또는 다른 추천 테마 클릭 유도.
2. **위치 권한 거부 시**:
   - 안내 문구: "위치 정보를 가져올 수 없습니다. 브라우저 위치 권한을 확인해주세요." 안내 후 기본 전국 화면 유지.
3. **이미지 미등록 또는 깨짐 발생 시**:
   - 빈 엑스박스 대신 서비스 전용 기본 그래픽 이미지를 대체 노출함.
