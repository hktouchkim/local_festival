# 지역축제 서비스 기능 및 정책 정의서

본 문서는 전국 지역축제 인터랙티브 지도 플랫폼의 서비스 개요, 이용 흐름, 사용자 인터페이스(UI), 상세 화면 구성, 운영 관리자 기능, 시스템 및 데이터 정책을 기술함.

---

## 1. 서비스 개요

### 1.1. 목적 및 대상
- **목적**: 전국 각지의 지역축제 정보를 지도 중심의 직관적인 인터랙션을 통해 쉽게 탐색하고 상세 정보를 열람할 수 있는 플랫폼을 제공함.
- **데이터 출처**: 한국관광공사 공공데이터(TourAPI)를 연동·가공하여 독자적인 축제 데이터베이스로 구축 및 운영함.
- **주요 대상**: 주말 여행객, 가족 단위 나들이객, 지역 문화행사 탐색자.
- **제공 환경**: 반응형 웹 (PC 및 모바일 웹 브라우저 완벽 대응).

### 1.2. 기본 운영 원칙
- **단일 화면 완결형 구조**: 불필요한 하단 스크롤을 배제하고 상단 헤더, 풀스크린 지도, 탐색 패널의 유기적 결합을 통해 단일 화면 내에서 모든 탐색을 완결함.
- **일일 1회 정기 갱신**: 한국관광공사 데이터를 매일 1회 정기 동기화하여 자체 데이터베이스로 관리함 (사용자 화면 접속 시 외부 API를 실시간 호출하지 않고 자체 DB를 조회하여 초고속 응답과 서비스 안정성을 보장함).
- **자체 화면 완결형 상세 정보**: 축제 개요, 이용요금, 운영시간, 상세 소개, 행사 프로그램, 현장 갤러리까지 서비스 내부 상세 화면에서 원스톱으로 제공함.

### 1.3. 지도 개발 사양 및 핵심 구현 지침
- **프로토타입 환경**: 빠른 기능 검증 및 사용성 테스트를 위해 카카오 지도(Kakao Maps SDK) 기반으로 구축함.
- **상용 서비스 개발 지침 (필수 준수 사항)**:
  - **상용 서비스 개발 시에는 한국경제 닷컴(hankyung.com) 표준 환경에 맞추어 네이버 지도(Naver Maps API v3)로 전환 개발함.**
  - 프로토타입에서 검증 완료된 지도 영역(`Bounds`) 필터링, 부드러운 화면 이동(글라이딩), 축척 제어, 마커 그룹화(클러스터링), 반응형 중심점 보정 로직을 네이버 지도 기능으로 1:1 동일하게 구현함.

### 1.4. 한경 트래블 사이트 연동 및 서브메뉴 개편 정책
- **한경 트래블 상단 서브메뉴(GNB) 개편 사항**:
  - 기존 서브메뉴 중 **커뮤니티** 및 **검색** 메뉴 2종을 서비스 정리 정책에 따라 전면 삭제함.
  - 서브메뉴 **우측 끝 위치에 `지역축제` 신규 메뉴 버튼을 신설**하여 메인 진입점으로 연결함.
- **진입점 동작 정책**:
  - 사용자 클릭 시 전국 지역축제 인터랙티브 지도 화면으로 즉시 이동함.
  - 최초 진입 시 별도의 검색어 없이 현재 '진행중'인 전국 축제 목록이 지도에 기본 로드됨.

## 2. 사용자 이용 흐름 (User Flow)

사용자가 한경 트래블을 통해 지역축제 서비스에 진입하여 탐색하는 전체 흐름은 다음과 같음:

```
[한경 트래블 상단 메뉴]
   │
   ▼ ('지역축제' 클릭)
[지역축제 메인 지도 화면]
   │
   ├─► [상단 헤더] ── 브랜드 로고 및 타이틀 노출
   │
   ├─► [메인 지도 영역]
   │       ├─► 전국 축제 마커 및 클러스터링(밀집 숫자) 표기 (검색 패널과 100% 동기화)
   │       ├─► 내 위치 찾기 (GPS 연동 현 위치 지도 이동)
   │       └─► 개별 축제 마커 클릭 ──► 우측 플로팅 상세 패널 오픈 & 해당 위치로 지도 포커싱
   │
   ├─► [좌측 검색 및 탐색 패널] (모바일은 하단 서랍형 바텀시트)
   │       ├─► 통합 검색창 (축제명 / 지역명 검색 및 X 버튼 리셋)
   │       ├─► 추천 테마 롤링 배너 (한경 트래블 PICK 등 선택 시 테마 축제 즉시 필터링)
   │       ├─► 결과 카운트 안내 ("총 OO개의 축제가 있습니다.")
   │       ├─► 진행 상태 다중 필터 (진행중 / 예정 / 종료 체크박스 토글)
   │       └─► 축제 목록 피드 (일정순 정렬 카드)
   │               │
   │               ▼ (축제 카드 클릭)
   └─► [플로팅 상세 정보 패널] (모바일은 풀사이즈 바텀시트 모달)
           ├─► 대표 포스터 (원본 비율 노출 및 터치 시 라이트박스 확대)
           ├─► 헤더 정보 (진행 상태 뱃지, 축제명, 공유하기 링크 복사)
           ├─► 핵심 메타 정보 (기간, 도로명 주소, 운영시간, 이용요금, 문의처 전화걸기)
           ├─► 길찾기 연동 (네이버지도, 카카오맵 길찾기 아웃링크)
           ├─► 상세 소개글 (데이터 부재 시 준비 중 안내 모듈 유지)
           ├─► 주요 행사 프로그램 (데이터 부재 시 안내 모듈 유지)
           ├─► 부대행사 및 특별 프로그램 (데이터 부재 시 안내 모듈 유지)
           ├─► 현장 갤러리 피드 (세로 피드 노출 및 사진 확대 뷰어)
           └─► 공식 홈페이지 바로가기 (외부 새 창 연결)
```

## 3. 메인 화면 구성 및 상세 인터페이스(UI) 정의

### 3.1. 상단 헤더
- **화면 배치**: 최상단 고정 노출.
- **구성 요소**:
  - 브랜드 로고 및 서비스 명칭 표기 (`지역축제`).
  - 지도 화면 영역을 최대로 확보하기 위해 로그인 및 기타 부가 메뉴는 전면 배제함.

### 3.2. 메인 지도 화면
- **화면 점유**: 헤더를 제외한 화면 전체 영역을 채움.
- **지도 컨트롤 및 인터랙션**:
  - **내 위치 찾기 버튼**: 우측 하단에 배치하며, 클릭 시 기기 GPS 기반으로 현재 위치로 지도 중심을 이동함.
  - **마커 표기 및 데이터 일치**: 축제의 진행 상태별로 마커 색상을 구분 표기하며, 밀집 지역은 숫자로 묶어 표시하는 클러스터링을 적용함. 지도 상의 마커는 좌측 검색/필터 패널의 목록 결과와 항상 100% 일치하도록 연동함.
  - **화면 영역 제한 배제**: 지도 이동이나 확대/축소 시 별도의 재검색 버튼('현 지도에서 검색') 없이, 검색 조건에 부합하는 모든 축제가 지도 상에 온전히 유지됨.

### 3.3. 검색 및 탐색 패널
- **화면 점유**: PC 환경은 좌측 상시 고정 패널로 배치하며, 모바일 환경은 하단 서랍형 바텀시트로 구성함.
- **PC 지도 중심축 시야 보정**: PC에서는 좌측 패널 너비로 인해 한반도 지도가 치우쳐 보이지 않도록 중심점을 보정하여 우측 가시 영역 중앙에 안정적으로 위치하도록 함.
- **패널 내부 UI 구성 순서**:
  1. **통합 검색창**:
     - 축제명 또는 지역명(시/군/구) 입력 검색 지원.
     - 검색어 입력 시 노출되는 삭제(X) 버튼 클릭 시, 검색어 지움과 동시에 필터 및 지도 화면이 초기 기본 상태로 리셋됨.
     - 상세 공유 링크로 유입된 경우에도 삭제(X) 버튼을 누르면 주소창 파라미터가 정리되며 기본 전국 화면으로 복귀함.
  2. **추천 테마 배너**:
     - 상단에 추천 테마를 롤링 배너 형태로 노출하여 직관적인 테마 탐색 유도.
     - 주목도가 높은 밝고 화사한 색상톤 적용.
     - 서브 카피: `에디터가 엄선한 실패 없는 전국 대표 축제`
     - 배너 클릭 시 해당 테마에 부합하는 축제 목록이 노출되며, 반복 클릭해도 목록 상태를 안정적으로 유지함.
  3. **검색 결과 안내 문구**: 현재 조건에 해당하는 축제 건수를 명확한 문장(`총 OO개의 축제가 있습니다.`)으로 안내.
  4. **진행 상태 필터 (체크박스 다중 선택)**:
     - `진행중`, `예정`, `종료` 상태를 사용자가 자유롭게 조합하여 볼 수 있도록 다중 선택 필터 제공.
  5. **축제 목록 피드 및 일정순 정렬**:
     - 현재 지도 범위 및 선택 필터에 부합하는 축제 카드를 목록으로 제공.
     - 카드 전체를 터치 영역으로 구성하여 간결하게 상세 화면으로 연결.
     - **정렬 우선순위**:
       - 1순위: 현재 방문 가능한 **진행 중 축제** 최우선 노출 (종료 마감일 임박순).
       - 2순위: 곧 방문 가능한 **진행 예정 축제** 차순위 노출 (개막일 임박순).
       - 3순위: 이미 끝난 **종료 축제** 최하단 노출 (최근 종료일순).

### 3.4. 모바일 전용 사용자 인터페이스(UI) 정책
- **모바일 첫 진입 지도 시야 최적화 정책**:
  - 모바일 첫 진입 시 하단 서랍형 바텀시트에 의해 남부 지방이나 제주도가 가려지지 않도록 초기 지도 축척을 넓게 조정하고 중심점을 남쪽으로 보정하여, 사용자가 조작하지 않아도 한반도 전역의 주요 축제가 첫 화면에 시원하게 들어오도록 함.
- **서랍형 바텀시트 인터랙션**:
  - **접힘 상태**: 지도 시야를 극대화하기 위해 검색창 영역만 하단에 콤팩트하게 노출.
  - **펼침 상태**: 중앙 핸들바를 위로 밀어 올리거나 검색창을 터치하면 화면 대부분을 덮는 풀스크린 형태로 부드럽게 확장되어 추천 배너, 필터, 축제 목록을 탐색할 수 있도록 함.
  - **스크롤 제스처 분리**: 목록 스크롤이 맨 위에 닿은 상태에서만 바텀시트를 아래로 닫을 수 있도록 제스처를 분리하여 사용성을 보호함.
- **모바일 상세화면 인터랙션**:
  - 모바일에서 축제 선택 시 전체 화면을 시원하게 채우는 풀사이즈 시트로 전환되며, 핸들바를 아래로 쓸어내려 손쉽게 닫고 이전 탐색 화면으로 복귀 가능함.

## 4. 축제 상세 화면 구성 사양

### 4.1. 노출 및 내비게이션 정책
- **노출 시점**: 목록 카드 클릭 또는 지도 상의 개별 마커 클릭 시 즉시 노출.
- **배치 형태**: PC에서는 좌측 검색 패널 우측에 나란히 플로팅 노출되며, 모바일에서는 화면을 채우는 바텀시트 모달로 노출됨.
- **스크롤 위치 초기화 정책**: 상세 패널이 열려 있는 상태에서 다른 축제를 연속으로 선택하더라도, 이전 축제의 스크롤 잔류 없이 항상 상세 화면의 맨 위부터 표시되도록 함.
- **상단 내비게이션 및 공유**:
  - **닫기(X) 버튼**: 패널을 닫고 이전 지도/목록 탐색 상태로 복귀.
  - **공유하기 버튼**: 현재 축제 상세 페이지 접속 URL을 클립보드에 복사하고 안내 토스트를 표출함.

### 4.2. 상단 비주얼 영역 (대표 포스터)
- 포스터 원본 비율을 보존하여 상하 잘림 없이 온전하게 노출하며, 좌우 여백 영역을 자연스럽게 배경 마감 처리함.
- 포스터 클릭 시 화면 전체를 활용한 라이트박스 확대 뷰어를 제공함.

### 4.3. 기본 정보 및 핵심 메타 정보 영역
- **진행 상태 뱃지**: `진행중`, `D-Day / D-N(진행 예정)`, `종료`로 구분 노출.
- **축제명**: 축제 공식 명칭을 강조 표기.
- **행사 기간**: 시작일 및 종료일을 명확히 표기.
- **개최 장소**: 도로명 주소를 기본 표기하며 지번 주소를 보조 표기함.
- **운영 시간**: 축제 운영 및 관람 시간 정보 표출.
- **이용 요금**: 무료 또는 유료 세부 요금 정보를 표출함.
- **문의처**: 대표 전화번호를 표기하고 모바일 환경에서 터치 시 즉시 전화 걸기(`tel:`) 기능을 지원함.

### 4.4. 길찾기 연동
- 축제 행사장 위치로 즉시 길 안내를 받을 수 있도록 네이버지도 및 카카오맵 길찾기 바로가기 아웃링크 버튼을 제공함.

### 4.5. 축제 소개 및 행사 프로그램 모듈 (모듈 유지 정책)
- **축제 소개 모듈**:
  - 축제 개요 및 상세 취지 소개글 표출.
  - **데이터 부재 시 정책**: 등록된 소개 데이터가 없는 경우에도 모듈 박스 영역을 유지하며, `"상세 축제 소개 정보가 준비 중입니다."` 안내 문구를 표출함.
- **주요 행사 프로그램 모듈**:
  - 주요 공연, 퍼레이드, 무대 행사 등 일정표 데이터 표출.
  - **데이터 부재 시 정책**: 등록된 프로그램 데이터가 없는 경우에도 모듈 박스 영역을 유지하며, `"등록된 주요 행사 프로그램 정보가 없습니다. 상세 일정은 공식 홈페이지를 참고해주세요."` 안내 문구를 표출함.
- **부대행사 및 특별 프로그램 모듈**:
  - 상설 체험 부스, 부대행사 안내 텍스트 표출.
  - **데이터 부재 시 정책**: 등록된 부대행사 데이터가 없는 경우에도 모듈 박스 영역을 유지하며, `"등록된 부대행사 및 특별 프로그램 정보가 없습니다."` 안내 문구를 표출함.

### 4.6. 현장 갤러리 피드
- 한국관광공사 TourAPI의 서브 이미지 데이터를 연동하여 사진 목록을 표출함.
- 타일 형태 대신 아래로 스크롤하며 시원하게 감상할 수 있는 1열 피드 형태로 사진을 배치함.
- 사진 터치 시 전체 화면 확대 뷰어를 제공하며 이전/다음 사진 탐색 기능을 지원함.

### 4.7. 공식 홈페이지 바로가기
- 공식 웹사이트 주소 데이터가 존재하는 경우 외부 새 창으로 안전하게 연결되는 버튼을 제공함.

## 5. 기능 및 데이터 연동 정책

### 5.1. 기본 진입 화면 및 테마 검색 연동
- **기본 진입 상태**: 사용자가 처음 접속 시 특정 테마가 선택되지 않은 순수 기본 상태로 로드되며, 현재 개최 중인 **'진행 중' 전국 축제**를 최우선으로 안내함. (상단 배너 클릭 시 언제든 원하는 테마로 즉시 전환 탐색 가능)
- **추천 테마 선별 조건**:
  - `한경 트래블 PICK`: 축제 소개글 또는 행사 프로그램 설명이 충실히 등록되어 있고, 현장 사진이 최소 1장 이상 등록된 현재 진행 중 또는 예정인 대표 축제만을 엄선하여 노출.
  - `뮤직 & 페스티벌`: 대중음악, 락, 재즈, 콘서트, 버스킹, 맥주 관련 축제 자동 연동.
  - `야간 & 빛 축제`: 야간 개장, 빛, 불꽃, 달빛, 밤, 나이트, 드론 관련 축제 자동 연동.

### 5.2. 상태 필터 및 종료 축제 조회 제한 정책
- **기본 선택 상태**: `진행 중(선택)`, `진행 예정(선택)`, `종료(미선택)`.
- **종료 축제 조회 기간 제한 정책 (성능 및 데이터 과부하 방지)**:
  - '종료' 축제는 최근 1년 이내에 종료된 축제까지만 한정 노출함.
  - 1년이 지난 과거 데이터는 목록 및 지도에서 제외하여 화면 렌더링 부하 및 탐색 피로도를 방지함.

### 5.3. 지도-목록 연동 및 카메라 이동 정책
- **검색 결과와 지도 마커 100% 일치 정책**: 사용자가 검색창에 키워드를 입력하거나 진행 상태 필터를 변경하면, 검색 패널의 축제 목록과 지도 상에 표시되는 모든 마커가 완전히 동일한 데이터 집합으로 동기화됨. 지도를 이동하더라도 목록의 축제가 임의로 제외되거나 마커가 사라지지 않음.
- **목록 선택 시 지도 연동**: 목록에서 특정 축제를 선택하면 해당 위치로 부드럽게 글라이딩 이동함. 이때 패널에 마커가 가려지지 않도록 시야를 고려한 최적 중심점에 포커싱됨.
- **자유로운 지도 탐색 보장**: 사용자가 지도를 자유롭게 이동하거나 줌을 변경하더라도 검색 패널 목록이 유지되어, 지도 탐색 중에도 전체 검색 결과를 언제든 확인하고 선택할 수 있도록 함.

## 6. 운영 관리자 화면 및 정책

### 6.1. 관리자 개요
- 등록된 축제 데이터의 노출 상태를 제어하고, 공공 API에 미반영된 축제를 수동 등록할 수 있는 자체 운영 관리자 화면(`/admin`)을 제공함.

### 6.2. 축제 목록 관리 및 공개 상태 제어
- **목록 항목**: 식별번호(ID), 축제명, 개최 기간, 개최 지역, 데이터 출처(공공 API 수집 / 수동 등록), 노출 상태.
- **공개/숨김 상태 제어**:
  - 축제별로 즉시 공개/숨김 상태를 전환할 수 있는 토글 스위치 제공.
  - 운영자가 '숨김' 처리한 축제는 사용자 화면(지도 마커, 검색 결과, 테마 큐레이션)에서 즉시 실시간 제외됨.

### 6.3. 신규 축제 수동 등록
- 공공 API에 아직 등재되지 않았거나 긴급 등록이 필요한 주요 축제를 위해 관리자 직접 입력 양식을 제공함.
- **입력 항목**: 축제명, 행사 시작일 및 종료일, 개최 장소(주소), 지도 좌표(위경도), 대표 이미지 주소, 이용 요금, 운영 시간, 상세 소개글, 문의처 전화번호, 홈페이지 주소.

## 7. 시스템 및 예외 처리 정책

### 7.1. 시스템 및 데이터 수집 정책
- **데이터베이스 단일 풀 관리**: 데이터베이스 연결 자원을 효율적으로 관리하기 위해 연결 인스턴스를 재사용함.
- **외부 API 장애 격리**: 공공 API 서버 장애 시에도 서비스가 중단되지 않도록 사전에 자체 DB로 적재된 정기 동기화 데이터를 기반으로 서비스함.

### 7.2. 예외 상황 처리 및 사용자 안내 정책
1. **검색 결과 0건 시**:
   - 안내 문구: "검색 조건에 맞는 축제가 없습니다. 지도를 다른 지역으로 이동해보세요."
   - 조치 권유: 검색어 초기화(X) 또는 다른 추천 테마 클릭 유도.
2. **존재하지 않거나 삭제된 축제 접근 시**:
   - URL 파라미터(`festivalId`)로 전달된 축제가 DB에 없거나 숨김 처리된 경우, 오류 화면 대신 주소창을 정리하고 기본 전체 지도 뷰로 부드럽게 유도함.
3. **위치 권한 거부 시**:
   - 안내 문구: "위치 정보를 가져올 수 없습니다. 브라우저 위치 권한을 확인해주세요." 토스트 안내 후 기본 전국 화면 유지.
4. **이미지 미등록 또는 깨짐 발생 시**:
   - 빈 엑스박스 아이콘 대신 서비스 전용 기본 그래픽 이미지를 대체 노출함.
