# 한경 지역축제 서비스 기획 정의서

본 문서는 한경 트래블 하위 서비스인 '한경 지역축제'의 최종 화면 구조, 기능 사양, 정책, 인터랙션 및 데이터 연동 기준을 기술함. 디자이너, 퍼블리셔, 개발자가 즉시 구현 및 검증할 수 있도록 완벽한 개조식 문체로 작성함.

---

## 1. 서비스 개요

### 1.1. 서비스 목적
- 전국 각지의 축제 정보를 지도 및 큐레이션 형태로 직관적으로 제공하여 주말 나들이 및 여행 탐색 편의성 극대화.
- 한국관광공사 TourAPI 공공 데이터를 가공·축적하여 한경 트래블만의 독자적 축제 플랫폼 구축.

### 1.2. 기본 운영 원칙
- **일일 1회 정기 갱신 운영 (B안 채택)**: 한국관광공사 TourAPI 데이터를 매일 새벽 1회 정기 동기화하여 자체 DB로 운영함 (사용자 접속 시 실시간 외부 API 호출 배제).
- **상세 완결형 서비스**: 목록 및 상세 API를 DB에 일괄 적재하여 외부 이탈 없이 서비스 내부에서 축제 개요, 이용요금, 운영시간, 상세 소개, 행사 프로그램, 서브 갤러리까지 완결형으로 제공함.
- **반응형 웹 지원**: PC 및 모바일 환경을 모두 지원하며, 반응형 와이드 지도 및 모바일 플로팅 인터랙션 제공함.
- **브랜드 일관성**: 한경 공식 네이비(`#0A2540`) 및 포인트 레드(`#e83428`)를 메인 컬러로 사용함.
- **서비스 기준일자**: 프로토타입 및 데모 운영 기준일은 `2026-09-04`로 프로젝트 전역 단일 상수로 통합 관리함.

## 2. 상단 네비게이션(GNB) 개편 정책

### 2.1. 상단 메뉴 변경
- 기존 한경 트래블 메뉴 중 `커뮤니티`, `검색` 2개 항목 삭제함.
- 삭제된 위치에 `지역축제` 신규 메뉴 항목 추가함.
- `지역축제` 클릭 시 메인 화면(`/`)으로 이동함.
- 공통 영역(로고, 로그인 등)은 기존 규격 동일 유지함.

## 3. 사용자 이용 흐름

```
[한경 트래블 GNB]
       │
       ▼ ('지역축제' 클릭)
[지역축제 메인 화면 (/)]
       │
       ├─► [전면 와이드 지도 영역]

       │       ├─► 내 위치 기반 지도 중심 이동 (GPS 기능)
       │       ├─► 지도 마커 클릭 ──► 커스텀 오버레이 팝업 표출 (상세보기 클릭 시 상세페이지 이동)
       │       └─► 우측 플로팅 목록 패널 ──► 축제 미니 카드 클릭 시 지도 포커싱 및 팝업 연동
       │
       ├─► [메인 큐레이션 섹션 (스크롤 하단)]
       │       ├─► 테마 1: 지금 가장 핫한 축제 TOP 10 (진행중 + 예정 분배)
       │       ├─► 테마 2: 흥 폭발! 뮤직 & 페스티벌
       │       ├─► 테마 3: 낭만 가득 야간 & 빛 축제
       │       └─► 테마 4: 온 가족 & 아이와 함께 가기 좋은 축제
       │               │ (수평 캐러셀 스와이프 탐색 및 카드 클릭)
       │               ▼
       └─► [축제 상세 화면 (/festivals/[id])]
               ├─► 1. 상단 비주얼 영역 (포스터 전체 노출 및 연회색 배경)
               ├─► 2. 헤더 타이틀 영역 (D-Day 뱃지, 축제명, 공유하기)
               ├─► 3. 핵심 메타 정보 그리드 (일시, 장소, 시간, 요금, 문의처 등)
               ├─► 4. 축제 소개 본문 (값 부재 시에도 모듈 박스 항시 유지)
               ├─► 5. 주요 행사 프로그램 일정표 (값 부재 시에도 모듈 박스 항시 유지)
               ├─► 6. 부대행사 (데이터 보유 시 노출)
               ├─► 7. 축제 현장 갤러리 (TourAPI 서브 이미지 연동 및 라이트박스 뷰어)
               └─► 8. 공식 홈페이지 바로가기 외부 링크
```

## 4. 메인 화면 구성 및 상세 기능 정의

### 4.1. 전면 와이드 지도 영역
- **화면 배치**: 메인 상단 전면에 높이 520px(모바일) ~ 620px(PC) 와이드 지도 배치함.
- **내부 플로팅 검색/필터 바 (상단 좌측)**:
  - 축제명 검색 인풋 및 실시간 검색어 초기화(X) 버튼 지원함.
  - 일정 탭: `전체 일정`, `이번 주말`, `이번 달` 3종 탭 버튼 제공함.
  - 지역 태그: `전국`, `서울`, `경기/인천`, `강원`, `충청`, `전라`, `경상`, `제주` 버튼 제공함.
  - 상태 체크박스: `진행중`, `예정`, `종료` 개별 필터링 지원함.
- **내 위치 탐색 (GPS 버튼)**: 지도 우측 하단 플로팅 버튼 클릭 시 현재 사용자 위치로 지도 중심 이동 및 마커 탐색 기능 제공함.
- **지도 마커 및 커스텀 오버레이 팝업**:
  - 마커 클릭 시 해당 축제 정보 오버레이 팝업 노출함.
  - 오버레이 표기: 썸네일, 상태 뱃지, 축제명, 행사 기간, 주소, `상세보기` 버튼.
  - `상세보기` 클릭 시 이벤트 전파 차단(`stopPropagation`)을 통해 에러 없이 해당 축제 상세 페이지(`/festivals/[id]`)로 안전하게 라우팅 이동함.
- **우측 플로팅 목록 패널 (PC/태블릿)**:
  - 지도 우측에 검색 결과 목록을 세로 카드 리스트로 실시간 렌더링함.
  - 접기/펼치기 토글 버튼 지원하여 지도 탐색 시야 확보 가능함.
  - 카드 클릭 시 지도 중심 이동 및 상세 이동 지원함.

### 4.2. 메인 테마 큐레이션 캐러셀 섹션
- **4개 테마 구성**:
  1. **지금 가장 핫한 축제 TOP 10**: 현재 진행 중인 축제와 오픈 임박(D-Day) 축제를 균형 있게 추천함.
  2. **흥 폭발! 뮤직 & 페스티벌**: 음악, 락, 재즈, 비어, 버스킹 관련 축제 선별 노출함.
  3. **낭만 가득 야간 & 빛 축제**: 야간개장, 불꽃, 드론, 미디어아트, 달빛 테마 축제 선별 노출함.
  4. **온 가족 & 아이와 함께 가기 좋은 축제**: 어린이, 가족, 체험, 캐릭터, 생태 테마 축제 선별 노출함.
- **캐러셀 인터랙션**:
  - 마우스 휠 및 좌우 내비게이션 화살표 버튼을 통한 부드러운 가로 스크롤 제공함.
  - 카드 표기: 16:9 비율 대표 포스터, 상태 뱃지(진행중/D-Day/종료), 축제명, 기간, 개최지.
  - 카드 클릭 시 즉시 해당 축제 상세 페이지(`/festivals/[id]`)로 이동함.

## 5. 축제 상세 화면 구성 사양 (`/festivals/[id]`)

### 5.1. 상단 비주얼 영역 (대표 포스터)
- **포스터 이미지 표출 정책 (개선 확정)**:
  - 이미지 핏: `object-contain` 적용하여 세로형 포스터 원본이 상하 잘림 없이 전체 온전하게 노출됨.
  - 컨테이너 배경: 좌우 여백 영역은 연회색(`bg-slate-100`)으로 마감하여 시각적 안정감 제공함.
  - 높이: 모바일 340px, PC 460px 고정 규격 적용함.
- **내비게이션 및 액션**: 좌측 상단 '목록으로' 뒤로가기 버튼, 우측 상단 '공유하기(URL 클립보드 복사)' 버튼 배치함.

### 5.2. 헤더 타이틀 영역
- **진행 상태 및 D-Day 뱃지 (3단 차별화)**:
  - 진행 중: 초록색 뱃지 (`진행 중` + 펄스 애니메이션).
  - 진행 예정: 레드 뱃지 (`D-Day` 또는 `D-N (진행 예정)`).
  - 종료: 그레이 뱃지 (`종료된 축제`).
- **축제명**: 대형 볼드 타이틀 표출함.

### 5.3. 핵심 메타 정보 그리드 (2단 그리드 박스)
- **개최 기간**: `YYYY-MM-DD ~ YYYY-MM-DD` 표기.
- **개최 장소**: 도로명 주소 표기 (`addr1`).
- **이용 요금**: 무료 / 유료 및 요금 상세 텍스트 표기 (`usetime`).
- **관람 소요 시간**: 데이터 보유 시 노출 (`spendtimefestival`).
- **문의처**: 전화번호 텍스트 표기 및 터치 시 전화 걸기(`tel:`) 연결 지원함 (`tel`).

### 5.4. 축제 상세 소개 본문 (모듈 영역 항시 유지)
- **표시 정책**: 데이터(`overview`)가 비어 있거나 등록되지 않은 경우에도 모듈 컨테이너 영역을 항상 렌더링함.
- **안내 문구**: 데이터 부재 시 `"상세 축제 소개 정보가 준비 중입니다."` 기본 안내 텍스트 노출함.
- **주최/주관사**: 데이터 보유 시 하단에 아이콘과 함께 표기함 (`sponsor1`, `sponsor2`).

### 5.5. 주요 행사 프로그램 일정표 (모듈 영역 항시 유지)
- **표시 정책**: 데이터(`program`)가 비어 있거나 등록되지 않은 경우에도 모듈 박스 구조를 유지하여 화면 레이아웃 일관성을 확보함.
- **안내 문구**:
  - 데이터 존재 시: 일정표 텍스트 서술 박스 노출함.
  - 데이터 부재 시: `"등록된 주요 행사 프로그램 정보가 없습니다. 상세 일정은 공식 홈페이지를 참고해주세요."` 기본 안내문 노출함.

### 5.6. 부대행사 모듈
- 데이터(`subevent`)가 존재하는 축제에 한하여 선택적으로 노출함.

### 5.7. 축제 현장 갤러리 모듈 (원복 확정)
- **위치**: 축제 상세 소개 및 주요 행사 프로그램 모듈 하단에 배치함 (원복 완료).
- **데이터 출처**: 한국관광공사 TourAPI `detailImage2` 서브 이미지 목록 실시간 연동함.
- **인터랙션**:
  - 가로 슬라이더 형태의 포토 썸네일 그리드 제공함.
  - 사진 클릭 시 화면 전체 라이트박스(Lightbox) 뷰어 모달 오픈 및 고화질 확대, 이전/다음 이미지 탐색 지원함.

### 5.8. 공식 홈페이지 아웃링크
- 축제 공식 웹사이트(`homepage`) URL 데이터가 존재하는 경우 최하단에 '공식 홈페이지 바로가기' 버튼 배치함 (새 창 열림).

## 6. 운영 관리자 화면 및 정책 (`/admin`)

### 6.1. 관리자 개요
- **목적**: 등록된 축제의 공개/숨김 상태 제어 및 공공 API 미반영 자체/제휴 축제 신규 등록함.
- **접근 경로**: `/admin` 단독 페이지 제공함.

### 6.2. 축제 목록 관리
- **표기 항목**: 번호, 축제명(클릭 시 상세 미리보기), 개최 기간, 개최 지역, 데이터 출처(`TourAPI` / `수동등록`), 공개 상태.
- **상태 토글 기능**: 버튼 클릭 시 `공개 중(PUBLISHED)` / `숨김(HIDDEN)` 상태 즉시 토글 업데이트함. 숨김 처리된 축제는 메인 지도, 검색, 큐레이션 목록에서 즉시 제외됨.

### 6.3. 신규 축제 수동 등록
- 관리자가 직접 제목, 기간, 장소, 위경도 좌표, 대표 이미지 URL, 이용요금, 운영시간, 상세 소개글을 입력하여 DB에 단건 등록(`source: MANUAL`) 가능함.

## 7. 시스템 아키텍처 및 공통 기준 정책

### 7.1. 기준 일자 단일화 정책 (`SERVICE_TODAY`)
- 서비스 기준 일자를 `'2026-09-04'`로 설정하고, `lib/data.ts`의 `SERVICE_TODAY` 단일 상수를 메인, 상세, 지도, 큐레이션, API 전역에서 임포트하여 참조함.

### 7.2. 데이터베이스 연결 관리
- Serverless 환경 연결 풀 고갈을 방지하기 위해 `lib/db.ts`의 `sql` 인스턴스를 공유 export하여 API 라우트 전역에서 단일 재사용함.

### 7.3. 예외 및 에러 처리
- **ID 불일치 예외 (404 Not Found)**: 유효하지 않은 축제 ID 접근 시 Next.js 표준 `notFound()` 에러 화면으로 안전하게 포워딩함.
- **런타임 크래시 방지**: 지도 마커 및 오버레이 팝업 렌더링 시 전역 스코프 참조 에러가 발생하지 않도록 상위 모듈 스코프 상수 및 `router.push` 바인딩을 적용함.
