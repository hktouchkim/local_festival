# 지역축제 서비스 기능 및 정책 정의서

본 문서는 전국 지역축제 인터랙티브 지도 플랫폼의 화면 구성, 사용자 기능, 동작 정책 및 데이터 필터링 규칙을 정의함.

---

## 1. 서비스 개요

### 1.1. 목적 및 사용자 환경
- **서비스 목적**: 전국 지역축제 정보를 지도 기반 인터랙션을 통해 직관적으로 탐색하고 세부 행사 정보를 열람할 수 있는 플랫폼을 제공함.
- **주요 대상**: 주말 여행객, 가족 나들이객, 축제·문화행사 탐색자.
- **제공 환경**: 반응형 웹 (PC 웹 브라우저 및 모바일 웹 브라우저 완벽 대응).

### 1.2. 화면 및 운영 기본 정책
- **단일 화면 완결형 구조**: 하단 스크롤 영역을 배제하고 상단 헤더와 풀스크린 지도 및 좌측 탐색 패널로 단일 화면에서 모든 탐색을 완결함.
- **데이터 주기**: 일 1회 정기 수집 및 데이터베이스 갱신 정책을 유지함.

### 1.3. 지도 SDK 개발 사양 및 핵심 구현 지침 (중요 개발자 전달 사항)
- **프로토타입 환경**: 빠른 검증 및 구현을 위해 카카오 지도(Kakao Maps SDK) 기반으로 인터랙션 프로토타입을 구축함.
- **상용 실제 개발 환경 (필수 준수 사항)**:
  - **실제 상용 서비스 개발 시에는 한국경제 닷컴(hankyung.com)에서 표준으로 사용 중인 네이버 지도(Naver Maps API v3)로 전환 개발함.**
  - 본 프로토타입에서 검증 완료된 지도 영역(`Bounds`) 필터링, 부드러운 패닝 글라이딩(`panTo`), 줌 레벨 제어, 클러스터링, 반응형 중심 좌표 보정 로직은 네이버 지도 SDK 메서드로 1:1 대응하여 구현함.

## 2. 화면 구조 및 사용자 인터페이스(UI) 구성

### 2.1. 상단 공통 헤더
- **화면 배치**: 최상단 고정 노출 (높이 56px).
- **구성 요소**:
  - 브랜드 로고 및 서비스 명칭 표기 (`지역축제`).
  - 지도 화면 영역을 극대화하기 위해 우측 부가 메뉴 및 유틸리티 링크는 전면 배제함.

### 2.2. 메인 지도 화면
- **화면 점유**: 브라우저 창 전체 높이(`100vh - 헤더높이`)를 채움.
- **지도 컨트롤**:
  - 우측 하단: `내 위치 찾기` 원형 버튼 배치 (GPS 기반 현 위치 이동 기능).
  - 축제 위치 마커 표기: 진행 상태에 따른 마커 색상 구분 표기 및 대량 마커 밀집 시 클러스터링 표기.
  - 지도 이동 시 '현 지도에서 검색' 플로팅 버튼 노출 정책 (사용자 수동 드래그/줌 조작 시에만 노출).

### 2.3. 좌측 검색 및 탐색 패널 (PC/모바일 공통 UI 순서)
- **화면 점유**: PC 환경은 좌측 390px 상시 고정 패널(접기/펼치기 토글 배제), 모바일 환경은 하단 바텀시트로 구성함.
- **PC 지도 중심축 보정**: PC에서는 좌측 390px 패널 너비를 감안하여 지도의 초기 중심 경도를 동쪽(보정 경도: 약 127.35)으로 조정하여 우측 가시 영역 중앙에 한반도가 위치하도록 정렬함.
- **UI 순서 규격**:
  1. **검색창**: 축제명 또는 지번/도로명 주소 입력 지원. 별도의 초기화 버튼은 삭제하고, 검색어 입력 시 우측에 나타나는 `X` 버튼 클릭 시 검색어 삭제 및 필터 전체 초기화(Reset)가 일원화되어 실행됨.
     - **초기화 시 브라우저 주소창 동기화 정책**: 상세 공유 URL(`?festivalId=...`)로 진입했더라도 `X` 버튼 클릭 시 브라우저 주소창의 파라미터를 완전히 제거(루트 `/`로 변경)하고, 검색어 없음, 진행중 ON, 예정 OFF, 종료 OFF 상태의 전국 지도로 리셋함.
  2. **추천 배너**: 1단 컴팩트 롤링 추천 테마 배너 및 하단 도트 인디케이터.
     - **한경 트래블 PICK 배너 디자인 사양**: 주목도를 높이기 위해 밝은 앰버-옐로우 골드 그라데이션 및 딥 슬레이트 텍스트 컬러를 적용함.
     - **서브 소개 카피**: `에디터가 엄선한 실패 없는 전국 대표 축제`
     - **배너 클릭 인터랙션 정책**: 배너 재클릭 시 선택이 해제되는 토글 기능을 배제하고, 클릭 시 항상 해당 테마의 검색결과 목록을 안정적으로 노출함.
  3. **검색결과 안내 문구**: `총 OO개의 축제가 있습니다.` 형태의 명확한 문장으로 현재 조건에 부합하는 축제 건수 안내.
  4. **기간 필터 배제**: 기존 `전체`, `이번 주`, `이번 달` 기간 필터 탭은 배제하여 UI 복잡도를 낮춤.
  5. **진행 상태 필터 (체크박스 형태 중복 선택 가능)**:
     - `진행중` (초록색 체크 뱃지)
     - `예정` (빨간색 체크 뱃지)
     - `종료` (회색 체크 뱃지)
     - 사용자가 원하는 상태 조합을 자유롭게 다중 선택(on/off)할 수 있는 체크박스 토글 규격으로 동작함.
  6. **축제 목록 피드 및 기본 정렬 정책**:
     - 현재 지도 화면 범위 및 필터 조건에 부합하는 축제 카드 목록 노출.
     - **목록 정렬 순서 (사용자 친화적 일정순)**:
       - **1순위 (진행 중 축제)**: 현재 방문 가능한 축제를 최상단에 우선 배치 (종료 마감일 임박순 정렬).
       - **2순위 (진행 예정 축제)**: 곧 방문 가능한 축제를 차순위 배치 (개막 임박순 정렬).
       - **3순위 (종료 축제)**: 이미 종료된 축제는 최하단 배치 (최근 종료일순 정렬).
     - 카드 항목: 포스터 썸네일, 축제명, 진행 상태 뱃지, 기간, 주소.
     - 카드 전체가 클릭 가능한 영역으로 동작하므로 별도의 `상세 →` 텍스트 버튼은 배제함.

### 2.4. 플로팅 상세 정보 패널 (축제 선택 시 노출)
- **노출 시점**: 좌측 목록에서 특정 축제 카드를 클릭하거나 지도 상의 개별 마커를 클릭했을 때 노출됨.
- **배치 위치**: PC에서는 상시 고정된 좌측 검색 패널의 우측에 16px 간격을 두고 나란히 플로팅 노출되며, 모바일에서는 화면 하단에서 올라오는 전체 바텀시트 모달로 노출됨.
- **축제 연속 탐색 시 스크롤 위치 초기화 정책 (React Key 할당 규격)**:
  - 축제 상세 패널이 열려 있는 상태에서 다른 축제를 연속 클릭할 경우, 이전 축제의 스크롤 잔류 현상을 방지하기 위해 패널 컴포넌트에 고유 키(`key={selectedFestival.id}`)를 할당하여 무조건 최상단(0px)부터 즉시 렌더링되도록 구현함.
- **상세 패널 내부 구성**:
  - 상단 대표 썸네일: 잘림 없는 원본 비율 노출 및 클릭 시 전체 화면 라이트박스 확대 뷰 제공.
  - 기본 정보: 축제명, 진행 상태, 행사 기간, 도로명/지번 주소, 전화번호, 홈페이지 바로가기 링크.
  - 행사 개요 및 소개 본문.
  - 길찾기 지원: 카카오맵 길찾기 및 네이버지도 길찾기 원클릭 아웃링크 버튼 제공.
  - 현장 갤러리 피드: 타일 형태 대신 아래로 스크롤하여 크게 볼 수 있는 1열 피드 형태로 사진 노출.
  - 패널 우측 상단 닫기(`X`) 버튼 지원.

### 2.5. 모바일 전용 사용자 인터페이스(UI) 사양
- **모바일 첫 진입 시 지도 뷰포트 최적화 정책 (A안 반영)**:
  - 모바일 진입 시 하단 바텀시트(`88px`)에 의해 남부 지역 및 제주도가 가려지지 않도록 **줌 레벨을 13으로 한 단계 확장**하고, **중심 위도를 남쪽(`35.75`)으로 하향 보정**하여 사용자가 손대지 않아도 첫눈에 대한민국 전역과 주요 축제 마커가 완벽히 시야에 들어오도록 렌더링함.
- **화면 영역 배분 및 검색 바텀시트 정책**:
  - **접힘 상태 (Collapsed)**: 바텀시트 접힘 시 검색창 하단 여백까지 안정적으로 노출함 (`h-[88px]`).
  - **상단 서랍 손잡이 (Handle bar)**: 복잡한 안내 텍스트를 제거하고 심플한 중앙 드래그 바만 유지.
  - **펼침 상태 (Expanded)**: 드래그 업 또는 검색창 포커스 시 풀페이지(`h-[96dvh]`)로 부드럽게 확장.
  - **콘텐츠 내부 제스처 분리**: 목록 내부 스크롤이 최상단에 도달한 상태에서 재차 아래로 스크롤할 때만 바텀시트가 접힘 상태로 축소됨.
  - **모서리 라운딩**: 축소 및 확장 상태 모두 좌우 상단 모서리에 미려한 라운딩 곡률(`rounded-t-3xl`)을 상시 유지함.
- **축제 상세화면 풀사이즈 바텀시트 사양**:
  - 목록 카드 또는 마커 터치 시 지도 영역 없이 화면 전체를 시원하게 채우는 풀사이즈(`h-[95vh]`) 바텀시트로 표시함.
  - 좌우 상단 모서리에 `rounded-t-3xl` 라운딩 곡률을 적용함.
  - 상단 핸들바의 불필요한 '내려서 닫기' 텍스트 및 모바일 화면의 `X` 닫기 버튼을 삭제하여 시야를 극대화함.
  - 꼭지 드래그 바를 잡고 아래로 쓸어내리거나 본문 최상단에서 아래로 스와이프 시 닫힘.
- **내 위치 찾기 버튼**:
  - 모바일에서는 접혀있는 하단 바텀시트에 가려지지 않도록 바텀시트 바로 위 우측(`bottom-24`)에 플로팅 배치되며, 풀페이지 확장 시에는 자동으로 숨김 처리함.

## 3. 기능 및 데이터 연동 정책

### 3.1. 축제 검색 및 키워드 매핑 정책
- **기본 진입 화면 (Default State)**:
  - 사용자가 지역축제 페이지에 최초 진입 시 **'한경 트래블 PICK'**이 기본 선택된 상태로 로드됨.
  - 검색창에 `한경 트래블 PICK` 자동 입력, 상단 배너 활성화, 진행 상태 필터는 `진행중(ON)`, `예정(ON)`, `종료(OFF)`로 초기화되어 최상의 알짜 축제 목록을 첫 화면에 즉시 제공함.
- **일반 검색**: 축제명의 부분 일치 또는 주소의 시/군/구/읍/면 일치 시 노출함.
- **추천 테마 검색어 연동 정책**:
  - 사용자가 검색창에 직접 입력하거나 추천 배너를 클릭하여 아래 키워드가 전달된 경우, 단순 텍스트 일치 축제만 찾는 것이 아니라 해당 테마의 정의 규칙을 적용하여 풍부한 축제 목록을 제공함:
    - `한경 트래블 PICK`:
      - **조건 1**: 축제 소개글(`overview`) 또는 주요 행사 프로그램(`program`) 중 최소 하나 이상에 유효한 본문 데이터가 존재할 것.
      - **조건 2**: 축제 현장 갤러리에 **사진이 반드시 1장 이상** 등록되어 있을 것.
      - **조건 3**: 현재 `진행중`인 축제 및 `진행 예정`인 축제 전체를 선별 매핑함.
    - `뮤직 & 페스티벌`: 축제명 또는 개요에 음악, 락, 재즈, 콘서트, 버스킹, 맥주 키워드가 포함된 축제 자동 매핑.
    - `야간 & 빛 축제`: 축제명 또는 개요에 야간, 빛, 불꽃, 달빛, 밤, 나이트, 드론 키워드가 포함된 축제 자동 매핑.

### 3.2. 상태 필터 및 종료 축제 조회 제한 정책
- **기본 상태**:
  - `진행 중`: 기본 활성화 (ON)
  - `진행 예정`: 기본 활성화 (ON, 한경 트래블 PICK 기본 진입에 대응)
  - `종료 (1년 이내)`: 기본 비활성화 (OFF)
- **종료 축제 조회 기간 제한 정책 (성능 및 데이터 과부하 방지)**:
  - '종료' 체크박스 선택 시, 서비스 기준일로부터 **종료일이 최근 1년 이내(종료일 >= 서비스기준일 - 1년)인 축제만 한정 노출함.**
  - 1년이 초과된 과거 축제 데이터는 지도 마커 렌더링 렉 및 불필요한 서버 부하 방지를 위해 목록 및 지도에서 제외 처리함.
- **예외 상황 처리**:
  - 3개 체크박스가 모두 해제된 경우: "선택된 상태 조건이 없습니다" 상태로 처리하여 결과 0건으로 표기함.

### 3.3. 지도-목록 연동 및 인터랙션 정책
- **목록 선택 시 지도 연동**:
  - 목록에서 축제 선택 시 해당 좌표로 순간 점프하지 않고, 부드러운 글라이딩(부드러운 이동) 기법을 적용하여 이동함.
  - 좌측 패널에 가려지지 않도록 화면 중심에서 우측으로 적정 픽셀만큼 보정된 중심점에 축제 위치를 포커싱함.
  - 이때는 시스템에 의한 자동 이동이므로 '현 지도에서 검색' 버튼은 노출하지 않음.
- **사용자 지도 조작 시 연동**:
  - 사용자가 직접 지도를 드래그하거나 줌을 변경한 경우에만 '현 지도에서 검색' 버튼을 화면 상단 중앙에 노출함.
  - '현 지도에서 검색' 버튼을 누르면 현재 보고 있는 지도 영역 좌표 범위(`Bounds`) 내의 축제만 좌측 목록에 즉시 재정렬 노출함.

### 3.4. 내 위치 연동 정책
- 브라우저 위치 권한 허용 시: 현재 GPS 좌표로 지도 중심 이동 및 내 위치 마커 노출.
- 위치 권한 거부 또는 미지원 시: "위치 정보를 가져올 수 없습니다. 브라우저 위치 권한을 확인해주세요." 안내 토스트 메시지 노출 후 기존 전국 중심 좌표 유지.

## 4. 예외 처리 및 사용자 안내 정책

1. **검색 결과 0건 발생 시**:
   - 안내 문구: "검색 조건에 맞는 축제가 없습니다. 지도를 다른 지역으로 이동해보세요."
   - 조치 권유: 상단 '초기화' 버튼 또는 다른 추천 배너 클릭 유도.
2. **네트워크 또는 서버 통신 장애 시**:
   - 지도 상단에 "축제 데이터를 불러오는데 실패했습니다. 잠시 후 다시 시도해주세요." 안내 배너 노출.
3. **이미지 누락(깨진 이미지) 축제 건**:
   - 깨진 이미지 아이콘 대신 서비스 기본 축제 플레이스홀더 그래픽을 대체 노출함.
